Twilio Live Voice provides 1 trigger for automating workflows based on events.

Triggers [#triggers]

Twilio Live Voice [#twilio-live-voice]

Hold a live, two-way voice conversation on a phone call. The agent speaks, listens, and replies in real time.

Configuration [#configuration]

| Parameter         | Type           | Required | Description                                                                                                                                                                                     |
| ----------------- | -------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `authToken`       | api-key-picker | Yes      | Twilio connection used to verify the webhook signature                                                                                                                                          |
| `welcomeGreeting` | string         | No       | Spoken to the caller as soon as the call connects, before they say anything.                                                                                                                    |
| `realtimeWssUrl`  | string         | No       | Base wss\:// URL of the realtime websocket server. Leave empty to derive it from the incoming request host (use this when the websocket is served on a different host/tunnel than the webhook). |
| `ttsVoice`        | string         | No       | Text-to-speech voice for ConversationRelay. Leave empty for the Twilio default.                                                                                                                 |
| `language`        | string         | No       | Language for speech recognition and synthesis. Leave empty for the default.                                                                                                                     |

Output [#output]

| Parameter      | Type   | Description                                                                 |
| -------------- | ------ | --------------------------------------------------------------------------- |
| `callSid`      | string | Unique identifier for this call                                             |
| `accountSid`   | string | Twilio Account SID                                                          |
| `from`         | string | Caller's phone number (E.164 format)                                        |
| `to`           | string | Recipient phone number (your Twilio number)                                 |
| `callStatus`   | string | Status of the call                                                          |
| `direction`    | string | Call direction: inbound or outbound                                         |
| `speechResult` | string | The caller's latest spoken utterance, transcribed (one conversational turn) |
| `raw`          | string | Complete raw payload for the current turn as a JSON string                  |
