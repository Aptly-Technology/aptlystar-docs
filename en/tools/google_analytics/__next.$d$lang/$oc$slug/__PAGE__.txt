Usage Instructions [#usage-instructions]

Send custom events to Google Analytics 4 using the Measurement Protocol (Measurement ID + API secret). Wire an upstream block (e.g., GEO Readiness) into the event name and parameters to log analytics events that GA can read.

For GEO Custom AI Output Setup with a GA4 profile, wire:

* Event Name ← `<georeadiness.payloads.ga4.event_name>`
* Event Parameters ← `<georeadiness.payloads.ga4.params>`

For GEO’s built-in Google Analytics output format (non-custom), use the event fields on that run’s output (for example `event_name` / `params` under destination convenience roots when that preset is selected). For the full analysis JSON, use `<georeadiness.fullreport>`.

Tools [#tools]

google_analytics_send_event [#google_analytics_send_event]

Send a GA4 event via the Measurement Protocol so it can be read in Google Analytics reports.

Input [#input]

| Parameter            | Type    | Required | Description                                                                                                        |
| -------------------- | ------- | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `measurementId`      | string  | Yes      | GA4 Measurement ID (e.g., G-XXXXXXX) from Admin → Data Streams                                                     |
| `apiSecret`          | string  | Yes      | Measurement Protocol API secret (Admin → Data Streams → Measurement Protocol)                                      |
| `clientId`           | string  | No       | Client ID that groups events to a user/device. Defaults to "geo.audit".                                            |
| `eventName`          | string  | Yes      | GA4 event name (lowercase, \<=40 chars), e.g., geo\_audit                                                          |
| `eventParams`        | json    | No       | Event parameters object (or JSON string). Wire GEO Custom GA4 profile as \<georeadiness.payloads.ga4.params>.      |
| `sessionId`          | string  | No       | Optional GA4 session\_id event parameter.                                                                          |
| `engagementTimeMsec` | number  | No       | Optional GA4 engagement\_time\_msec event parameter.                                                               |
| `validationBehavior` | string  | No       | Optional GA4 validation behavior: RELAXED or ENFORCE\_RECOMMENDATIONS. Debug defaults to ENFORCE\_RECOMMENDATIONS. |
| `debug`              | boolean | No       | Use the GA4 debug endpoint to get validation messages instead of sending live.                                     |

Output [#output]

| Parameter            | Type   | Description                                   |
| -------------------- | ------ | --------------------------------------------- |
| `status`             | string | Result status message                         |
| `validationMessages` | json   | GA4 validation messages (debug endpoint only) |
