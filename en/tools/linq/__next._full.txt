{/* MANUAL-CONTENT-START:intro */}

[Linq](https://linqapp.com/) is a messaging API for sending iMessage, SMS, and RCS and managing conversations at scale.

With Linq in AptlyStar, your agents can:

* **Send rich messages**: Deliver text, media, links, effects, replies, and voice memos
* **Manage chats**: Create chats, add or remove participants, and mark conversations read
* **Check capabilities**: Verify whether a number supports iMessage or RCS before sending
* **Automate with webhooks**: Subscribe to delivery and inbound message events

Connect AptlyStar to Linq to power personalized outreach, support conversations, and notification workflows over modern messaging channels.

{/* MANUAL-CONTENT-END */}

Usage Instructions [#usage-instructions]

Reach people on iMessage, SMS, and RCS through Linq. Start chats, send messages with media, links, effects, and replies, send voice memos, react with tapbacks, manage group participants, check iMessage/RCS capability, configure contact cards, and subscribe to webhook events — all through a single Linq API key.

Tools [#tools]

linq_add_participant [#linq_add_participant]

Add a participant to a group chat (3+ existing participants)

Input [#input]

| Parameter | Type   | Required | Description                                                            |
| --------- | ------ | -------- | ---------------------------------------------------------------------- |
| `apiKey`  | string | Yes      | Linq API key                                                           |
| `chatId`  | string | Yes      | The unique identifier of the group chat                                |
| `handle`  | string | Yes      | Phone number (E.164 format) or email address of the participant to add |

Output [#output]

| Parameter | Type   | Description                    |
| --------- | ------ | ------------------------------ |
| `message` | string | Human-readable status message  |
| `status`  | string | Queued action status           |
| `traceId` | string | Trace ID for the queued action |
