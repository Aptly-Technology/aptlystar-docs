{/* MANUAL-CONTENT-START:intro */}

[AWS CodePipeline](https://aws.amazon.com/codepipeline/) is a continuous delivery service for fast and reliable application updates. You define a pipeline once and CodePipeline automates the build, test, and deploy phases whenever code changes.

With the CodePipeline integration, you can:

* **List Pipelines**: Enumerate pipelines in a region with metadata such as name, version, and creation time
* **Start Pipeline**: Trigger a pipeline execution on demand
* **Get Pipeline State**: Inspect stage and action status for a running or completed pipeline

In AptlyStar, CodePipeline pairs well with CloudFormation and CloudWatch blocks to build release orchestration, deployment verification, and incident response workflows.

{/* MANUAL-CONTENT-END */}
