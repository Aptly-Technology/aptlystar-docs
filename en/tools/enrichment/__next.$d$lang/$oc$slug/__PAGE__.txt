{/* MANUAL-CONTENT-START:intro */}

The **Data Enrichment** block runs AptlyStar's built-in enrichment providers to look up work emails, phone numbers, company domains, firmographic data, and more from the fields you map in the block.

With Data Enrichment in AptlyStar, your agents can:

* **Find work emails**: Resolve professional email addresses from name and company inputs
* **Enrich company profiles**: Pull domain, size, industry, and related firmographic attributes
* **Build full contact records**: Combine enrichment outputs into downstream workflow steps

Enrichments use the same provider cascade as AptlyStar table enrichments and run on your workspace's hosted or bring-your-own API keys — no separate credential block is required.

{/* MANUAL-CONTENT-END */}

Usage Instructions [#usage-instructions]

Run a Data enrichment to look up data — work email, phone number, company domain, company info, and more — from the fields you map in. Uses the same provider cascade as table enrichments.

Tools [#tools]

enrichment_run [#enrichment_run]

Run a Data enrichment (e.g. Work Email, Phone Number) and return its outputs

Input [#input]

| Parameter      | Type   | Required | Description                                 |
| -------------- | ------ | -------- | ------------------------------------------- |
| `enrichmentId` | string | Yes      | Registry enrichment id (e.g. "work-email")  |
| `inputs`       | json   | Yes      | Map of the enrichment's input ids to values |

Output [#output]

| Parameter  | Type    | Description                                                            |
| ---------- | ------- | ---------------------------------------------------------------------- |
| `matched`  | boolean | Whether the enrichment found a result                                  |
| `provider` | string  | Provider whose result was returned (e.g. "Hunter", "People Data Labs") |
