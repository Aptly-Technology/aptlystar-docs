Connection output envelope [#connection-output-envelope]

GEO returns a slim envelope so Connections stay easy to wire, plus `fullreport` for the complete analysis JSON:

| Path           | Type    | Use for                                                                                                 |
| -------------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `success`      | boolean | Whether analysis completed successfully                                                                 |
| `content`      | string  | Short human-readable summary                                                                            |
| `grade`        | string  | Letter grade A–F                                                                                        |
| `geoScore`     | number  | Score 0–100                                                                                             |
| `url`          | string  | Analyzed URL or text source label                                                                       |
| `fullreport`   | json    | Full analysis (factors, issues, recommendations, page breakdown, derived fields, dashboard snapshot, …) |
| `dashboardUrl` | string  | Persisted dashboard link when available                                                                 |

**Custom output format** also adds `payload` and `payloads.{name}` (e.g. `payloads.email`, `payloads.posthog`) from AI Output Setup / templates.

Example tags: `<georeadiness.content>`, `<georeadiness.fullreport>`, `<georeadiness.dashboardUrl>`, `<georeadiness.payloads.email.subject>`.

`dashboardUrl` is the only dashboard path (no `dashboardIdentifier` / `dashboardLink` on the envelope).

**AI Output Setup** (wand) generates Custom `outputProfiles`. Templates use flat placeholders such as `{{grade}}` / `{{derived.*}}` / `{{dashboardUrl}}` (same data as `fullreport`). Destination blocks wire from `payloads.{profile}.*`; Agents that need the whole report use `fullreport`.

{/* MANUAL-CONTENT-END */}

Usage Instructions [#usage-instructions]

Analyze GEO readiness for a single page, site crawl, or text draft. Connection outputs use a slim envelope: success, content, grade, geoScore, url, fullreport, and dashboardUrl.

Tools [#tools]

geo_analyze_page [#geo_analyze_page]

Fetch one URL and compute a single-page GEO readiness score with factor breakdowns and recommendations.

Input [#input]

| Parameter        | Type   | Required | Description                                                                                   |
| ---------------- | ------ | -------- | --------------------------------------------------------------------------------------------- |
| `url`            | string | Yes      | Public page URL to analyze                                                                    |
| `topics`         | string | No       | Optional comma-separated or newline-separated target topics to check for answer coverage      |
| `outputFormat`   | string | No       | Output shape: detailed, summary, scores-only, analytics/event presets, webhook, or custom     |
| `outputTemplate` | string | No       | JSON template used only when outputFormat is custom                                           |
| `outputProfiles` | string | No       | Named JSON templates rendered into payloads.\{profileKey} when outputFormat is custom         |
| `eventFields`    | string | No       | Optional comma/newline-separated analytics fields to include for event and row presets        |
| `responseFormat` | json   | No       | Optional Agent-style JSON Schema. Properties become flat GEO outputs filled from the analysis |

Output [#output]

| Parameter      | Type    | Description                                                                                |
| -------------- | ------- | ------------------------------------------------------------------------------------------ |
| `success`      | boolean | Whether the GEO analysis completed successfully                                            |
| `content`      | string  | Human-readable GEO summary (report text when available, otherwise a short score summary)   |
| `grade`        | string  | GEO readiness grade from A to F                                                            |
| `geoScore`     | number  | GEO readiness score from 0 to 100                                                          |
| `url`          | string  | Analyzed URL (or text source label)                                                        |
| `fullreport`   | json    | Complete GEO analysis payload (factors, issues, recommendations, dashboard snapshot, etc.) |
| `dashboardUrl` | string  | Persisted dashboard URL for this GEO run, when available                                   |
