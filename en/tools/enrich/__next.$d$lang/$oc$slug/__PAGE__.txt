{/* MANUAL-CONTENT-START:intro */}

[Enrich.so](https://enrich.so/) delivers real-time B2B data enrichment. Its v3 API provides dynamic access to public and structured contact, company, and professional information, enabling teams to build richer profiles, improve lead quality, and drive more effective outreach.

With Enrich.so, you can:

* **Enrich contact profiles**: Discover key data points for leads and prospects using an email address.
* **Find and verify emails**: Locate a person's work email from their name and company domain, then verify deliverability.
* **Find phone numbers**: Look up a phone number from an email address or LinkedIn profile URL.
* **Resolve IPs to companies**: Identify the organization behind a visitor IP address.
* **Find employees at a company**: Search for people at a target company by LinkedIn company URL.

The AptlyStar integration with Enrich.so empowers your agents and automations to instantly query and enrich B2B contact data, boosting productivity in workflows like sales prospecting, recruiting, and marketing operations.

**Note:** This integration mirrors Enrich's current v3 API. Enrich discontinued several operations that previously existed on its v1/v2 API — LinkedIn profile/post/activity search, company lookup/funding/revenue, reverse hash lookup, and logo search are no longer available through Enrich and are not exposed here. Enrich's Lead Finder (people/company search with a paid reveal step for contact info) is a different execution and credit model from the operations below and is not yet wired into this integration pending a product decision.

{/* MANUAL-CONTENT-END */}

Usage Instructions [#usage-instructions]

Access real-time B2B contact enrichment with Enrich.so. Enrich profiles from email addresses, find and verify work emails, find phone numbers, resolve IPs to companies, and find employees at a company.

Tools [#tools]

enrich_check_credits [#enrich_check_credits]

Check your Enrich API credit balance.

Input [#input]

| Parameter | Type   | Required | Description    |
| --------- | ------ | -------- | -------------- |
| `apiKey`  | string | Yes      | Enrich API key |

Output [#output]

| Parameter          | Type   | Description                                                                     |
| ------------------ | ------ | ------------------------------------------------------------------------------- |
| `totalCredits`     | number | Current credit balance (v3 does not expose a separate lifetime total)           |
| `creditsUsed`      | number | Always `0` — v3's wallet endpoint does not report usage separately from balance |
| `creditsRemaining` | number | Available credits remaining                                                     |

enrich_email_to_profile [#enrich_email_to_profile]

Retrieve detailed LinkedIn profile information using an email address, including work history, education, and skills.

Input [#input-1]

| Parameter    | Type    | Required | Description                                                                                                         |
| ------------ | ------- | -------- | ------------------------------------------------------------------------------------------------------------------- |
| `apiKey`     | string  | Yes      | Enrich API key                                                                                                      |
| `email`      | string  | Yes      | Email address to look up (e.g., [john.doe@company.com](mailto:john.doe@company.com)). Must be a valid email format. |
| `inRealtime` | boolean | No       | Set to true to retrieve fresh data, bypassing cached information                                                    |

Output [#output-1]

| Parameter                     | Type    | Description                                   |
| ----------------------------- | ------- | --------------------------------------------- |
| `displayName`                 | string  | Full display name                             |
| `firstName`                   | string  | First name                                    |
| `lastName`                    | string  | Last name                                     |
| `headline`                    | string  | Professional headline                         |
| `occupation`                  | string  | Current company name                          |
| `summary`                     | string  | Profile summary                               |
| `location`                    | string  | Location                                      |
| `country`                     | string  | Country (from profile locale)                 |
| `linkedInUrl`                 | string  | LinkedIn profile URL                          |
| `photoUrl`                    | string  | Profile photo URL                             |
| `connectionCount`             | number  | Number of connections                         |
| `isConnectionCountObfuscated` | boolean | Whether connection count is obfuscated (500+) |
| `positionHistory`             | array   | Work experience history                       |
| ↳ `title`                     | string  | Job title                                     |
| ↳ `company`                   | string  | Company name                                  |
| ↳ `startDate`                 | string  | Start date                                    |
| ↳ `endDate`                   | string  | End date                                      |
| ↳ `location`                  | string  | Location                                      |
| `education`                   | array   | Education history                             |
| ↳ `school`                    | string  | School name                                   |
| ↳ `degree`                    | string  | Degree                                        |
| ↳ `fieldOfStudy`              | string  | Field of study                                |
| ↳ `startDate`                 | string  | Start date                                    |
| ↳ `endDate`                   | string  | End date                                      |
| `skills`                      | array   | List of skills                                |
| `locale`                      | string  | Profile locale (e.g., en\_US)                 |

enrich_find_email [#enrich_find_email]

Find a person's work email address using their full name and company domain.

Input [#input-2]

| Parameter       | Type   | Required | Description                                                                                                                                                                |
| --------------- | ------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiKey`        | string | Yes      | Enrich API key                                                                                                                                                             |
| `fullName`      | string | Yes      | Person's full name — **must include both first and last name** (e.g., "John Doe"), per Enrich v3's schema. A first-name-only value is rejected before any request is sent. |
| `companyDomain` | string | Yes      | Company domain (e.g., example.com). Must be a valid domain — a protocol prefix (`https://`) or trailing path is stripped automatically.                                    |

Output [#output-2]

| Parameter   | Type    | Description                                       |
| ----------- | ------- | ------------------------------------------------- |
| `email`     | string  | Found email address                               |
| `firstName` | string  | First name                                        |
| `lastName`  | string  | Last name                                         |
| `domain`    | string  | Company domain                                    |
| `found`     | boolean | Whether an email was found                        |
| `acceptAll` | boolean | Whether the domain accepts all emails (catch-all) |

enrich_phone_finder [#enrich_phone_finder]

Find a phone number from a LinkedIn profile URL.

Input [#input-3]

| Parameter         | Type   | Required | Description                                                |
| ----------------- | ------ | -------- | ---------------------------------------------------------- |
| `apiKey`          | string | Yes      | Enrich API key                                             |
| `linkedinProfile` | string | Yes      | LinkedIn profile URL (e.g., linkedin.com/in/williamhgates) |

Output [#output-3]

| Parameter      | Type    | Description                             |
| -------------- | ------- | --------------------------------------- |
| `profileUrl`   | string  | LinkedIn profile URL that was looked up |
| `mobileNumber` | string  | Found mobile phone number               |
| `found`        | boolean | Whether a phone number was found        |
| `status`       | string  | Request status                          |

enrich_email_to_phone [#enrich_email_to_phone]

Find a phone number associated with an email address.

Input [#input-4]

| Parameter | Type   | Required | Description                                                                                                         |
| --------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------- |
| `apiKey`  | string | Yes      | Enrich API key                                                                                                      |
| `email`   | string | Yes      | Email address to look up (e.g., [john.doe@example.com](mailto:john.doe@example.com)). Must be a valid email format. |

Output [#output-4]

| Parameter      | Type    | Description                      |

enrich_verify_email [#enrich_verify_email]

Verify an email address for deliverability, including catch-all detection and provider identification.

Input [#input-5]

| Parameter | Type   | Required | Description                                                                                                        |
| --------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `apiKey`  | string | Yes      | Enrich API key                                                                                                     |
| `email`   | string | Yes      | Email address to verify (e.g., [john.doe@example.com](mailto:john.doe@example.com)). Must be a valid email format. |

Output [#output-5]

| Parameter         | Type    | Description                                                                                |
| ----------------- | ------- | ------------------------------------------------------------------------------------------ |
| `email`           | string  | Email address verified                                                                     |
