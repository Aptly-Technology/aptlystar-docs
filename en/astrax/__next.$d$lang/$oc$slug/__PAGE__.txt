Astrax is the AI assistant built into every workflow editor. It is scoped to the workflow you have open — it reads the current structure, makes changes directly, and saves checkpoints so you can revert if needed.

For workspace-wide tasks (managing multiple workflows, running research, working with tables, scheduling jobs), use [Astra](/astra).

<Callout type="info">
  Astrax is an Aptlystar-managed service. Sign in at [aptlystar.ai](https://aptlystar.ai), go to **Settings → Astrax**, generate an Astrax API key, and configure it where your workspace requires Astrax access.
</Callout>

What Astrax Can Do [#what-astrax-can-do]

Astrax can read and modify the workflow you are currently editing:

* Add, configure, and connect blocks
* Edit existing block configurations
* Delete blocks and connections
* Debug failures by reading execution logs
* Answer questions about the workflow or how Aptlystar works

Chat History [#chat-history]

Click **History** (clock icon) in the Astrax header to see past conversations for this workflow. Click any chat to resume it, or click **+** to start a new one.

File Attachments [#file-attachments]

Click the attachment icon in the input to upload files alongside your message. Astrax can read images, PDFs, and text-based files as context.

Checkpoints [#checkpoints]

When Astrax modifies a workflow, it saves a checkpoint of the previous state.

To revert: hover over a Astrax message and click the checkpoints icon, then click **Revert** on the state you want to restore. Reverting cannot be undone.

Thinking [#thinking]

For complex requests, Astrax may show its reasoning in an expandable thinking block before responding. The block shows how long the thinking took and collapses after the response is complete.

Usage [#usage]

Astrax usage is billed per token and counts toward your plan's credit usage. If you reach your limit, enable on-demand billing from Settings → Subscription.

Astrax MCP [#astrax-mcp]

You can use Astrax as an MCP server to build, test, and manage Aptlystar workflows from external editors — Cursor, Claude Code, Claude Desktop, and VS Code.

Generating a Astrax API Key [#generating-a-astrax-api-key]

1. Go to [aptlystar.ai](https://aptlystar.ai) and sign in
2. Navigate to **Settings** → **Astrax**
3. Click **Generate API Key**
4. Copy the key — it is only shown once

The key will look like `sk-aptlystar-astrax-...`.

Cursor [#cursor]

Add to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "url": "https://www.aptlystar.ai/api/mcp/astrax",
      "headers": {
        "X-API-Key": "YOUR_ASTRAX_API_KEY"
      }
    }
  }
}
```

Claude Code [#claude-code]

```bash
claude mcp add aptlystar-astrax \
  --transport http \
  https://www.aptlystar.ai/api/mcp/astrax \
  --header "X-API-Key: YOUR_ASTRAX_API_KEY"
```

Claude Desktop [#claude-desktop]

Claude Desktop requires [`mcp-remote`](https://www.npmjs.com/package/mcp-remote). Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.aptlystar.ai/api/mcp/astrax",
        "--header",
        "X-API-Key: YOUR_ASTRAX_API_KEY"
      ]
    }
  }
}
```

VS Code [#vs-code]

Add to `settings.json` or `.vscode/settings.json`:

```json
{
  "mcp": {
    "servers": {
      "aptlystar-astrax": {
        "type": "http",
        "url": "https://www.aptlystar.ai/api/mcp/astrax",
        "headers": {
          "X-API-Key": "YOUR_ASTRAX_API_KEY"
        }
      }
    }
  }
}
```
