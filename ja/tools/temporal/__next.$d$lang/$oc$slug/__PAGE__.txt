使用方法 [#使用方法]

Connect to a Temporal cluster over the server's HTTP API to start workflow executions, send signals, run queries against workflow state, describe and list executions, fetch event histories, and cancel or terminate running workflows. API key only required for servers with authentication enabled.

ツール [#ツール]

temporal_start_workflow [#temporal_start_workflow]

Start a new workflow execution on a Temporal cluster.

入力 [#入力]

| パラメータ                      | 型      | 必須  | 説明                                                                                                                                                                                                                                                          |
| -------------------------- | ------ | --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `serverUrl`                | string | はい  | Base URL of the Temporal server's HTTP API (e.g., [http://localhost:7243\\](http://localhost:7243\\))                                                                                                                                                       |
| `namespace`                | string | はい  | Temporal namespace (e.g., default)                                                                                                                                                                                                                          |
| `apiKey`                   | string | いいえ | API key sent as a Bearer token (leave blank for servers without auth)                                                                                                                                                                                       |
| `workflowId`               | string | はい  | Unique workflow ID for the new execution (e.g., order-1234)                                                                                                                                                                                                 |
| `workflowType`             | string | はい  | Registered workflow type name to run (e.g., OrderWorkflow)                                                                                                                                                                                                  |
| `taskQueue`                | string | はい  | Task queue the workflow worker polls (e.g., orders)                                                                                                                                                                                                         |
| `input`                    | string | いいえ | Workflow input as JSON. A top-level array is passed as the argument list (one argument per element); any other value is passed as a single argument                                                                                                         |
| `workflowIdReusePolicy`    | string | いいえ | Policy for reusing a closed workflow ID: WORKFLOW\_ID\_REUSE\_POLICY\_ALLOW\_DUPLICATE, WORKFLOW\_ID\_REUSE\_POLICY\_ALLOW\_DUPLICATE\_FAILED\_ONLY, WORKFLOW\_ID\_REUSE\_POLICY\_REJECT\_DUPLICATE, or WORKFLOW\_ID\_REUSE\_POLICY\_TERMINATE\_IF\_RUNNING |
| `workflowIdConflictPolicy` | string | いいえ | Policy when a workflow with the same ID is already running: WORKFLOW\_ID\_CONFLICT\_POLICY\_FAIL, WORKFLOW\_ID\_CONFLICT\_POLICY\_USE\_EXISTING, or WORKFLOW\_ID\_CONFLICT\_POLICY\_TERMINATE\_EXISTING                                                     |
| `cronSchedule`             | string | いいえ | Cron schedule for recurring executions (e.g., "0 12 \* \* \*")                                                                                                                                                                                              |
| `executionTimeoutSeconds`  | number | いいえ | Total workflow execution timeout in seconds, including retries and continue-as-new                                                                                                                                                                          |
| `runTimeoutSeconds`        | number | いいえ | Timeout for a single workflow run in seconds                                                                                                                                                                                                                |
| `memo`                     | string | いいえ | JSON object of memo fields to attach to the execution                                                                                                                                                                                                       |
| `searchAttributes`         | string | いいえ | JSON object of search attribute values to index the execution with                                                                                                                                                                                          |

出力 [#出力]

| パラメータ        | 型       | 説明                                                                                |
| ------------ | ------- | --------------------------------------------------------------------------------- |
| `workflowId` | string  | Workflow ID of the execution                                                      |
| `runId`      | string  | Run ID of the started workflow execution                                          |
| `started`    | boolean | Whether a new execution was started (false when an existing execution was reused) |

temporal_signal_workflow [#temporal_signal_workflow]

Send a signal to a running Temporal workflow execution.

入力 [#入力-1]

| パラメータ         | 型      | 必須  | 説明                                                                                                                                                |
| ------------- | ------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `serverUrl`   | string | はい  | Base URL of the Temporal server's HTTP API (e.g., [http://localhost:7243\\](http://localhost:7243\\))                                             |
| `namespace`   | string | はい  | Temporal namespace (e.g., default)                                                                                                                |
| `apiKey`      | string | いいえ | API key sent as a Bearer token (leave blank for servers without auth)                                                                             |
| `workflowId`  | string | はい  | Workflow ID of the execution to signal                                                                                                            |
| `runId`       | string | いいえ | Run ID of a specific run to signal (defaults to the latest run)                                                                                   |
| `signalName`  | string | はい  | Name of the signal handler to invoke (e.g., approve-order)                                                                                        |
| `signalInput` | string | いいえ | Signal input as JSON. A top-level array is passed as the argument list (one argument per element); any other value is passed as a single argument |

出力 [#出力-1]
