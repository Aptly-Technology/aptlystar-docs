使用方法 [#使用方法]

Connect to QuickBooks Online to read and write customers, invoices, and chart-of-accounts entries, or run arbitrary QuickBooks queries. Uses Intuit OAuth 2.0; the company (realmId) is captured from the OAuth callback at sign-in time.

ツール [#ツール]

quickbooks_create_bill [#quickbooks_create_bill]

Create a new bill (vendor expense) in QuickBooks Online

入力 [#入力]

| パラメータ      | 型      | 必須  | 説明                                                                             |
| ---------- | ------ | --- | ------------------------------------------------------------------------------ |
| `realmId`  | string | はい  | QuickBooks company ID (realmId) — captured at OAuth time                       |
| `vendorId` | string | はい  | Vendor ID for the bill                                                         |
| `lines`    | json   | はい  | Bill line items (JSON array). Each entry: \{ amount, accountId, description? } |
| `txnDate`  | string | いいえ | Transaction date (YYYY-MM-DD)                                                  |
| `dueDate`  | string | いいえ | Due date (YYYY-MM-DD)                                                          |

出力 [#出力]

| パラメータ           | 型      | 説明                                                        |
| --------------- | ------ | --------------------------------------------------------- |
| `bill`          | object | Created bill                                              |
| ↳ `Id`          | string | QuickBooks bill ID                                        |
| ↳ `VendorRef`   | object | Vendor reference                                          |
| ↳ `TxnDate`     | string | Transaction date (YYYY-MM-DD)                             |
| ↳ `DueDate`     | string | Due date (YYYY-MM-DD)                                     |
| ↳ `TotalAmt`    | number | Total bill amount                                         |
| ↳ `Balance`     | number | Outstanding balance                                       |
| ↳ `Line`        | array  | Bill line items                                           |
| ↳ `CurrencyRef` | object | Currency reference                                        |
| ↳ `MetaData`    | object | Create/update timestamps                                  |
| ↳ `SyncToken`   | string | Optimistic concurrency token; required for sparse updates |
| `billId`        | string | New bill ID                                               |

quickbooks_create_customer [#quickbooks_create_customer]

Create a new customer in QuickBooks Online

入力 [#入力-1]

| パラメータ          | 型      | 必須  | 説明                                                       |
| -------------- | ------ | --- | -------------------------------------------------------- |
| `realmId`      | string | はい  | QuickBooks company ID (realmId) — captured at OAuth time |
| `displayName`  | string | はい  | Display name (must be unique within the company)         |
| `companyName`  | string | いいえ | Company name                                             |
| `givenName`    | string | いいえ | First name                                               |
| `familyName`   | string | いいえ | Last name                                                |
| `primaryEmail` | string | いいえ | Primary email address                                    |
| `primaryPhone` | string | いいえ | Primary phone number                                     |
| `notes`        | string | いいえ | Free-form notes                                          |

出力 [#出力-1]

| パラメータ                | 型       | 説明                                                        |
| -------------------- | ------- | --------------------------------------------------------- |
| `customer`           | object  | Created customer                                          |
| ↳ `Id`               | string  | QuickBooks customer ID                                    |
| ↳ `DisplayName`      | string  | Display name shown in lists and forms                     |
| ↳ `CompanyName`      | string  | Company name                                              |
| ↳ `GivenName`        | string  | First name                                                |
| ↳ `FamilyName`       | string  | Last name                                                 |
| ↳ `PrimaryEmailAddr` | object  | Primary email object with `Address`                       |
| ↳ `PrimaryPhone`     | object  | Primary phone object with `FreeFormNumber`                |
| ↳ `Active`           | boolean | Whether the customer is active                            |
| ↳ `Balance`          | number  | Open balance owed by the customer                         |
| ↳ `CurrencyRef`      | object  | Currency reference (`value`, `name`)                      |
| ↳ `Notes`            | string  | Free-form notes                                           |
| ↳ `MetaData`         | object  | Create/update timestamps                                  |
| ↳ `SyncToken`        | string  | Optimistic concurrency token; required for sparse updates |
| `customerId`         | string  | New customer ID                                           |

quickbooks_create_invoice [#quickbooks_create_invoice]

Create a new invoice in QuickBooks Online

入力 [#入力-2]

| パラメータ          | 型      | 必須  | 説明                                                                                                                                                               |
| -------------- | ------ | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `realmId`      | string | はい  | QuickBooks company ID (realmId) — captured at OAuth time                                                                                                         |
| `customerId`   | string | はい  | Customer ID to bill                                                                                                                                              |
