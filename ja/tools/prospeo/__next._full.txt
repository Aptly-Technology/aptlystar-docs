Find verified work emails and mobile numbers, enrich person and company profiles, and search a B2B database of leads and companies using 20+ filters.

Retrieve the current plan, remaining credits, and renewal date of your Prospeo account.

入力 [#入力]

| パラメータ    | 型      | 必須 | 説明              |
| -------- | ------ | -- | --------------- |
| `apiKey` | string | はい | Prospeo API key |

出力 [#出力]

| パラメータ                     | 型      | 説明                                      |
| ------------------------- | ------ | --------------------------------------- |
| `current_plan`            | string | Current Prospeo plan name               |
| `current_team_members`    | number | Number of team members in your team     |
| `remaining_credits`       | number | Number of credits remaining             |
| `used_credits`            | number | Number of credits already used          |
| `next_quota_renewal_days` | number | Days until the next quota renewal       |
| `next_quota_renewal_date` | string | Date and time of the next quota renewal |

prospeo_enrich_person [#prospeo_enrich_person]

Enrich a person with complete B2B profile data, email address and mobile.

入力 [#入力-1]

| パラメータ                  | 型       | 必須  | 説明                                                                |
| ---------------------- | ------- | --- | ----------------------------------------------------------------- |
| `apiKey`               | string  | はい  | Prospeo API key                                                   |
| `first_name`           | string  | いいえ | First name of the person                                          |
| `last_name`            | string  | いいえ | Last name of the person                                           |
| `full_name`            | string  | いいえ | Full name of the person (alternative to first\_name + last\_name) |
| `linkedin_url`         | string  | いいえ | Person's public LinkedIn URL                                      |
| `email`                | string  | いいえ | Work email of the person                                          |
| `company_name`         | string  | いいえ | Company name                                                      |
| `company_website`      | string  | いいえ | Company website                                                   |
| `company_linkedin_url` | string  | いいえ | Company's public LinkedIn URL                                     |
| `person_id`            | string  | いいえ | Prospeo person\_id from a previous Search Person response         |
| `only_verified_email`  | boolean | いいえ | Only return records with a verified email                         |
| `enrich_mobile`        | boolean | いいえ | Reveal mobile number (10 credits per match; email included)       |
| `only_verified_mobile` | boolean | いいえ | Only return records that have a mobile (implies enrich\_mobile)   |

出力 [#出力-1]

| パラメータ             | 型       | 説明                                                                                                                                                   |
| ----------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `free_enrichment` | boolean | True if this enrichment was free (already enriched in the past)                                                                                      |
| `person`          | json    | The matched person object including person\_id, name, linkedin\_url, current\_job\_title, job\_history, mobile, email, location, and skills          |
| `company`         | json    | The current company of the matched person including name, website, domain, industry, employee\_count, location, social URLs, funding, and technology |
