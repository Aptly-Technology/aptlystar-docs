Quartr

Access earnings calls, transcripts, filings, and slides

使用方法

Integrate Quartr into the workflow. Look up public companies, corporate events, and event types; fetch AI-generated event summaries; list and download filings, reports, slide decks, and transcripts; and access archived audio and live event streams. Requires API Key.

ツール

quartr_list_companies

List companies covered by Quartr, filterable by ticker, ISIN, CIK, OpenFIGI, country, and exchange.

入力

パラメータ型必須説明
apiKeystringはいQuartr API key
tickersstringいいえComma-separated list of company tickers (e.g., "AAPL,MSFT")
isinsstringいいえComma-separated list of ISINs (e.g., "US0378331005")
ciksstringいいえComma-separated list of SEC CIKs (e.g., "0000320193")
countriesstringいいえComma-separated list of ISO 3166-1 alpha-2 country codes (e.g., "US,SE")
exchangesstringいいえComma-separated list of exchange symbols, without whitespace (e.g., "NasdaqGS")
companyIdsstringいいえComma-separated list of Quartr company IDs (e.g., "4742,128")
openfigisstringいいえComma-separated list of OpenFIGI codes (figi, compositeFigi, or shareClassFigi)
updatedAfterstringいいえOnly return data updated after this ISO 8601 date (e.g., "2024-01-01")
updatedBeforestringいいえOnly return data updated before this ISO 8601 date (e.g., "2024-12-31")
limitnumberいいえMaximum number of items to return in a single request (default: 10, max: 500)
cursornumberいいえPagination cursor from the previous response (nextCursor) for the next page
directionstringいいえSort direction by id: "asc" or "desc" (default: asc)

出力

パラメータ型説明
companiesarrayCompanies matching the filters
↳ idnumberQuartr company ID
↳ namestringLegal company name
↳ displayNamestringDisplay name
↳ countrystringISO 3166-1 alpha-2 country code
↳ tickersarrayTicker listings for the company
↳ tickerstringTicker symbol
↳ exchangestringExchange symbol
↳ isinsarrayISINs for the company
↳ cikstringSEC Central Index Key
↳ openfigiarrayOpenFIGI share class identifiers
↳ backlinkUrlstringQuartr backlink URL for the company
↳ createdAtstringCreation timestamp (ISO 8601)
↳ updatedAtstringLast update timestamp (ISO 8601)
nextCursornumberCursor for fetching the next page of results (null when no more pages)
