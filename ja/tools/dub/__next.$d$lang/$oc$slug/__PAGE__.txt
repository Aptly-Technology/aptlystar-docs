使用方法 [#使用方法]

Create, manage, and track short links with Dub. Supports custom domains, UTM parameters, link analytics, and more.

ツール [#ツール]

dub_create_link [#dub_create_link]

Create a new short link with Dub. Supports custom domains, slugs, UTM parameters, and more.

入力 [#入力]

| パラメータ          | 型       | 必須  | 説明                                                                  |
| -------------- | ------- | --- | ------------------------------------------------------------------- |
| `apiKey`       | string  | はい  | Dub API key                                                         |
| `url`          | string  | はい  | The destination URL of the short link                               |
| `domain`       | string  | いいえ | Custom domain for the short link (defaults to dub.sh)               |
| `key`          | string  | いいえ | Custom slug for the short link (randomly generated if not provided) |
| `externalId`   | string  | いいえ | External ID for the link in your database                           |
| `tagIds`       | string  | いいえ | Comma-separated tag IDs to assign to the link                       |
| `comments`     | string  | いいえ | Comments for the short link                                         |
| `expiresAt`    | string  | いいえ | Expiration date in ISO 8601 format                                  |
| `password`     | string  | いいえ | Password to protect the short link                                  |
| `rewrite`      | boolean | いいえ | Whether to enable link cloaking                                     |
| `archived`     | boolean | いいえ | Whether to archive the link                                         |
| `title`        | string  | いいえ | Custom OG title for the link preview                                |
| `description`  | string  | いいえ | Custom OG description for the link preview                          |
| `utm_source`   | string  | いいえ | UTM source parameter                                                |
| `utm_medium`   | string  | いいえ | UTM medium parameter                                                |
| `utm_campaign` | string  | いいえ | UTM campaign parameter                                              |
| `utm_term`     | string  | いいえ | UTM term parameter                                                  |
| `utm_content`  | string  | いいえ | UTM content parameter                                               |

出力 [#出力]

| パラメータ          | 型       | 説明                                          |
| -------------- | ------- | ------------------------------------------- |
| `id`           | string  | Unique ID of the created link               |
| `domain`       | string  | Domain of the short link                    |
| `key`          | string  | Slug of the short link                      |
| `url`          | string  | Destination URL                             |
| `shortLink`    | string  | Full short link URL                         |
| `qrCode`       | string  | QR code URL for the short link              |
| `archived`     | boolean | Whether the link is archived                |
| `externalId`   | string  | External ID                                 |
| `title`        | string  | OG title                                    |
| `description`  | string  | OG description                              |
| `tags`         | json    | Tags assigned to the link (id, name, color) |
| `clicks`       | number  | Number of clicks                            |
| `leads`        | number  | Number of leads                             |
| `sales`        | number  | Number of sales                             |
| `saleAmount`   | number  | Total sale amount in cents                  |
| `lastClicked`  | string  | Last clicked timestamp                      |
| `createdAt`    | string  | Creation timestamp                          |
| `updatedAt`    | string  | Last update timestamp                       |
| `utm_source`   | string  | UTM source parameter                        |
| `utm_medium`   | string  | UTM medium parameter                        |
| `utm_campaign` | string  | UTM campaign parameter                      |
| `utm_term`     | string  | UTM term parameter                          |
| `utm_content`  | string  | UTM content parameter                       |
