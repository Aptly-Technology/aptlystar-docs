使用方法 [#使用方法]

Integrate Daytona into your workflow to run AI-generated code in secure, isolated sandboxes. Create and manage sandboxes, execute shell commands, run Python, JavaScript, or TypeScript code, transfer files, and clone Git repositories.

ツール [#ツール]

daytona_create_sandbox [#daytona_create_sandbox]

Create a new Daytona sandbox for running AI-generated code in isolation

入力 [#入力]

| パラメータ                 | 型       | 必須  | 説明                                                                                 |
| --------------------- | ------- | --- | ---------------------------------------------------------------------------------- |
| `apiKey`              | string  | はい  | Daytona API key                                                                    |
| `snapshot`            | string  | いいえ | ID or name of the snapshot to create the sandbox from (uses default if empty)      |
| `name`                | string  | いいえ | Name for the sandbox (defaults to the sandbox ID)                                  |
| `target`              | string  | いいえ | Region where the sandbox will be created (e.g., us, eu)                            |
| `user`                | string  | いいえ | User associated with the sandbox                                                   |
| `env`                 | json    | いいえ | Environment variables to set in the sandbox as key-value pairs                     |
| `labels`              | json    | いいえ | Labels to attach to the sandbox as key-value pairs                                 |
| `cpu`                 | number  | いいえ | CPU cores to allocate to the sandbox                                               |
| `memory`              | number  | いいえ | Memory to allocate to the sandbox in GB                                            |
| `disk`                | number  | いいえ | Disk space to allocate to the sandbox in GB                                        |
| `autoStopInterval`    | number  | いいえ | Auto-stop interval in minutes (0 disables auto-stop)                               |
| `autoArchiveInterval` | number  | いいえ | Auto-archive interval in minutes (0 uses the maximum interval)                     |
| `autoDeleteInterval`  | number  | いいえ | Auto-delete interval in minutes (negative disables, 0 deletes immediately on stop) |
| `public`              | boolean | いいえ | Whether the sandbox HTTP preview is publicly accessible                            |

出力 [#出力]

| パラメータ     | 型    | 説明                  |
| --------- | ---- | ------------------- |
| `sandbox` | json | The created sandbox |

出力 [#出力-1]

| ------------ | ------ | ----------------------------------- |
| `sandboxes`  | array  | Sandboxes in the organization       |
