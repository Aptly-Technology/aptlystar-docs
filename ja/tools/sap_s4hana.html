SAP S4HANA

Read and write SAP S4HANA Cloud business data via OData

使用方法

Connect SAP S4HANA Cloud Public Edition with per-tenant OAuth 2.0 client credentials configured in your Communication Arrangements. Read and create business partners, customers, suppliers, sales orders, deliveries (inbound/outbound), billing documents, products, stock and material documents, purchase requisitions, purchase orders, and supplier invoices, or run arbitrary OData v2 queries against any whitelisted Communication Scenario.

ツール

sap_s4hana_list_business_partners

List business partners from SAP S/4HANA Cloud (API_BUSINESS_PARTNER, A_BusinessPartner) with optional OData $filter, $top, $skip, $orderby, $select, $expand.

入力

パラメータ型必須説明
subdomainstringはいSAP BTP subaccount subdomain (technical name of your subaccount, not the S/4HANA host)
regionstringはいBTP region (e.g. eu10, us10)
clientIdstringはいOAuth client ID from the S/4HANA Communication Arrangement
clientSecretstringはいOAuth client secret from the S/4HANA Communication Arrangement
deploymentTypestringいいえDeployment type: cloud_public (default), cloud_private, or on_premise
authTypestringいいえAuthentication type: oauth_client_credentials (default) or basic
baseUrlstringいいえBase URL of the S/4HANA host (Cloud Private / On-Premise)
tokenUrlstringいいえOAuth token URL (Cloud Private / On-Premise + OAuth)
usernamestringいいえUsername for HTTP Basic auth
passwordstringいいえPassword for HTTP Basic auth
filterstringいいえOData $filter expression (e.g., "BusinessPartnerCategory eq '1'")
topnumberいいえMaximum results to return ($top)
skipnumberいいえNumber of results to skip ($skip)
orderBystringいいえOData $orderby expression
selectstringいいえComma-separated fields to return ($select)
expandstringいいえComma-separated navigation properties to expand ($expand)

出力

パラメータ型説明
statusnumberHTTP status code returned by SAP
datajsonArray of A_BusinessPartner entities
