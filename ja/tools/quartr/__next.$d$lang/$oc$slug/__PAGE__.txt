使用方法 [#使用方法]

Integrate Quartr into the workflow. Look up public companies, corporate events, and event types; fetch AI-generated event summaries; list and download filings, reports, slide decks, and transcripts; and access archived audio and live event streams. Requires API Key.

ツール [#ツール]

quartr_list_companies [#quartr_list_companies]

List companies covered by Quartr, filterable by ticker, ISIN, CIK, OpenFIGI, country, and exchange.

入力 [#入力]

| パラメータ           | 型      | 必須  | 説明                                                                              |
| --------------- | ------ | --- | ------------------------------------------------------------------------------- |
| `apiKey`        | string | はい  | Quartr API key                                                                  |
| `tickers`       | string | いいえ | Comma-separated list of company tickers (e.g., "AAPL,MSFT")                     |
| `isins`         | string | いいえ | Comma-separated list of ISINs (e.g., "US0378331005")                            |
| `ciks`          | string | いいえ | Comma-separated list of SEC CIKs (e.g., "0000320193")                           |
| `countries`     | string | いいえ | Comma-separated list of ISO 3166-1 alpha-2 country codes (e.g., "US,SE")        |
| `exchanges`     | string | いいえ | Comma-separated list of exchange symbols, without whitespace (e.g., "NasdaqGS") |
| `companyIds`    | string | いいえ | Comma-separated list of Quartr company IDs (e.g., "4742,128")                   |
| `openfigis`     | string | いいえ | Comma-separated list of OpenFIGI codes (figi, compositeFigi, or shareClassFigi) |
| `updatedAfter`  | string | いいえ | Only return data updated after this ISO 8601 date (e.g., "2024-01-01")          |
| `updatedBefore` | string | いいえ | Only return data updated before this ISO 8601 date (e.g., "2024-12-31")         |
| `limit`         | number | いいえ | Maximum number of items to return in a single request (default: 10, max: 500)   |
| `cursor`        | number | いいえ | Pagination cursor from the previous response (nextCursor) for the next page     |
| `direction`     | string | いいえ | Sort direction by id: "asc" or "desc" (default: asc)                            |

出力 [#出力]

| パラメータ           | 型      | 説明                                                                     |
| --------------- | ------ | ---------------------------------------------------------------------- |
| `companies`     | array  | Companies matching the filters                                         |
| ↳ `id`          | number | Quartr company ID                                                      |
| ↳ `name`        | string | Legal company name                                                     |
| ↳ `displayName` | string | Display name                                                           |
| ↳ `country`     | string | ISO 3166-1 alpha-2 country code                                        |
| ↳ `tickers`     | array  | Ticker listings for the company                                        |
| ↳ `ticker`      | string | Ticker symbol                                                          |
| ↳ `exchange`    | string | Exchange symbol                                                        |
| ↳ `isins`       | array  | ISINs for the company                                                  |
| ↳ `cik`         | string | SEC Central Index Key                                                  |
| ↳ `openfigi`    | array  | OpenFIGI share class identifiers                                       |
| ↳ `backlinkUrl` | string | Quartr backlink URL for the company                                    |
| ↳ `createdAt`   | string | Creation timestamp (ISO 8601)                                          |
| ↳ `updatedAt`   | string | Last update timestamp (ISO 8601)                                       |
| `nextCursor`    | number | Cursor for fetching the next page of results (null when no more pages) |

quartr_get_company [#quartr_get_company]

Retrieve a single company from Quartr by its company ID.

入力 [#入力-1]

| パラメータ       | 型      | 必須 | 説明                             |
| ----------- | ------ | -- | ------------------------------ |
| `apiKey`    | string | はい | Quartr API key                 |
| `companyId` | number | はい | Quartr company ID (e.g., 4742) |

出力 [#出力-1]

| パラメータ           | 型      | 説明                                  |
| --------------- | ------ | ----------------------------------- |
| `company`       | object | The requested company               |
| ↳ `id`          | number | Quartr company ID                   |
| ↳ `name`        | string | Legal company name                  |
| ↳ `displayName` | string | Display name                        |
| ↳ `country`     | string | ISO 3166-1 alpha-2 country code     |
| ↳ `tickers`     | array  | Ticker listings for the company     |
| ↳ `ticker`      | string | Ticker symbol                       |
| ↳ `exchange`    | string | Exchange symbol                     |
| ↳ `isins`       | array  | ISINs for the company               |
| ↳ `cik`         | string | SEC Central Index Key               |
| ↳ `openfigi`    | array  | OpenFIGI share class identifiers    |
| ↳ `backlinkUrl` | string | Quartr backlink URL for the company |
| ↳ `createdAt`   | string | Creation timestamp (ISO 8601)       |
| ↳ `updatedAt`   | string | Last update timestamp (ISO 8601)    |

quartr_list_events [#quartr_list_events]

List corporate events (earnings calls, capital markets days, etc.) from Quartr, filterable by company, event type, and date range.

入力 [#入力-2]

| パラメータ           | 型      | 必須  | 説明                                                                              |
| --------------- | ------ | --- | ------------------------------------------------------------------------------- |
| `apiKey`        | string | はい  | Quartr API key                                                                  |
| `companyIds`    | string | いいえ | Comma-separated list of Quartr company IDs (e.g., "4742,128")                   |
| `tickers`       | string | いいえ | Comma-separated list of company tickers (e.g., "AAPL,MSFT")                     |
| `isins`         | string | いいえ | Comma-separated list of ISINs (e.g., "US0378331005")                            |
| `ciks`          | string | いいえ | Comma-separated list of SEC CIKs (e.g., "0000320193")                           |
| `countries`     | string | いいえ | Comma-separated list of ISO 3166-1 alpha-2 country codes (e.g., "US,SE")        |
| `exchanges`     | string | いいえ | Comma-separated list of exchange symbols, without whitespace (e.g., "NasdaqGS") |
| `eventTypeIds`  | string | いいえ | Comma-separated list of event type IDs (e.g., "26,27")                          |
| `startDate`     | string | いいえ | Only return events on or after this ISO 8601 date (e.g., "2024-01-01")          |
