Rootly

Manage incidents, alerts, and on-call with Rootly

使用方法

Integrate Rootly incident management into workflows. Create and manage incidents, alerts, services, severities, and retrospectives.

ツール

rootly_create_incident

Create a new incident in Rootly with optional severity, services, and teams.

入力

パラメータ型必須説明
apiKeystringはいRootly API key
titlestringいいえThe title of the incident (auto-generated if not provided)
summarystringいいえA summary of the incident
severityIdstringいいえSeverity ID to attach to the incident
statusstringいいえIncident status (in_triage, started, detected, acknowledged, mitigated, resolved, closed, cancelled, scheduled, in_progress, completed)
kindstringいいえIncident kind (normal, normal_sub, test, test_sub, example, example_sub, backfilled, scheduled, scheduled_sub)
serviceIdsstringいいえComma-separated service IDs to attach
environmentIdsstringいいえComma-separated environment IDs to attach
groupIdsstringいいえComma-separated team/group IDs to attach
incidentTypeIdsstringいいえComma-separated incident type IDs to attach
functionalityIdsstringいいえComma-separated functionality IDs to attach
labelsstringいいえLabels as JSON object, e.g. {"platform":"osx","version":"1.29"}
privatebooleanいいえCreate as a private incident (cannot be undone)

出力

パラメータ型説明
incidentobjectThe created incident
↳ idstringUnique incident ID
↳ sequentialIdnumberSequential incident number
↳ titlestringIncident title
↳ slugstringIncident slug
↳ kindstringIncident kind
↳ summarystringIncident summary
↳ statusstringIncident status
↳ privatebooleanWhether the incident is private
↳ urlstringURL to the incident
↳ shortUrlstringShort URL to the incident
↳ severityNamestringSeverity name
↳ severityIdstringSeverity ID
↳ createdAtstringCreation date
↳ updatedAtstringLast update date
↳ startedAtstringStart date
↳ mitigatedAtstringMitigation date
↳ resolvedAtstringResolution date
↳ closedAtstringClosed date
