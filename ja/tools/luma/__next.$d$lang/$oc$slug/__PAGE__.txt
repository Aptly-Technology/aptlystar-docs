luma_add_guests [#luma_add_guests]

Add guests to a Luma event by email. Guests are added with Going (approved) status and receive one ticket of the default ticket type.

入力 [#入力-8]

| パラメータ     | 型      | 必須 | 説明                                                                                                                                                                                                              |
| --------- | ------ | -- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiKey`  | string | はい | Luma API key                                                                                                                                                                                                    |
| `eventId` | string | はい | Event ID (starts with evt-)                                                                                                                                                                                     |
| `guests`  | string | はい | JSON array of guest objects. Each guest requires an "email" field and optionally "name", "first\_name", "last\_name". Example: \[\{"email": "[user@example.com](mailto:user@example.com)", "name": "John Doe"}] |

| ↳ `email`          | string | Guest email address                                                                       |
| ↳ `name`           | string | Guest full name                                                                           |
| ↳ `firstName`      | string | Guest first name                                                                          |
| ↳ `lastName`       | string | Guest last name                                                                           |
| ↳ `approvalStatus` | string | Guest approval status (approved, session, pending\_approval, invited, declined, waitlist) |
| ↳ `registeredAt`   | string | Registration timestamp (ISO 8601)                                                         |
| ↳ `invitedAt`      | string | Invitation timestamp (ISO 8601)                                                           |
| ↳ `joinedAt`       | string | Join timestamp (ISO 8601)                                                                 |
| ↳ `checkedInAt`    | string | Check-in timestamp (ISO 8601)                                                             |
| ↳ `phoneNumber`    | string | Guest phone number                                                                        |

luma_send_invites [#luma_send_invites]

Send email invitations to guests for a Luma event. Unlike Add Guests (which registers guests directly), this emails an invite that recipients can accept.

入力 [#入力-9]

| パラメータ     | 型      | 必須  | 説明                                                                                                                                                                                 |
| --------- | ------ | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiKey`  | string | はい  | Luma API key                                                                                                                                                                       |
| `eventId` | string | はい  | Event ID to invite guests to (starts with evt-)                                                                                                                                    |
| `guests`  | string | はい  | JSON array of guest objects. Each guest requires an "email" field and optionally "name". Example: \[\{"email": "[user@example.com](mailto:user@example.com)", "name": "John Doe"}] |
| `message` | string | いいえ | Optional custom message included in the invite email (max 200 characters)                                                                                                          |

出力 [#出力-9]

| パラメータ     | 型      | 説明                                    |
| --------- | ------ | ------------------------------------- |
| `invited` | number | Number of guests invited to the event |
