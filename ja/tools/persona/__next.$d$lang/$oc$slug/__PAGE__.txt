使用方法 [#使用方法]

Integrate Persona identity verification into the workflow. Manage the full inquiry lifecycle (create, update, approve, decline, review, resume, expire, redact), generate one-time verification links and PDF summaries, manage accounts including CSV bulk import, run watchlist and adverse media reports, review cases, retrieve verifications and documents, and discover inquiry templates.

ツール [#ツール]

persona_create_inquiry [#persona_create_inquiry]

Create a new identity verification inquiry from an inquiry template. Returns the created inquiry, which can then be completed by the individual via a one-time link.

入力 [#入力]

| パラメータ               | 型      | 必須  | 説明                                                                                                                                        |
| ------------------- | ------ | --- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `apiKey`            | string | はい  | Persona API key                                                                                                                           |
| `inquiryTemplateId` | string | はい  | Inquiry template ID (starts with itmpl\_), inquiry template version ID (starts with itmplv\_), or legacy template ID (starts with tmpl\_) |
| `accountId`         | string | いいえ | Account ID (starts with act\_) to associate with this inquiry                                                                             |
| `referenceId`       | string | いいえ | Reference ID that refers to an entity in your user model. An account is auto-created for it if one does not exist.                        |
| `fields`            | json   | いいえ | JSON object of field name to field value pairs to pre-fill, as defined by the inquiry template (e.g. \{"name-first": "Jane"})             |
| `note`              | string | いいえ | Free-form note to attach to the inquiry                                                                                                   |
| `redirectUri`       | string | いいえ | URI to redirect the individual to after completing the inquiry flow                                                                       |

出力 [#出力]

| パラメータ     | 型      | 説明                  |
| --------- | ------ | ------------------- |
| `inquiry` | object | The created inquiry |

persona_get_inquiry [#persona_get_inquiry]

Retrieve a single identity verification inquiry by ID, including its status, collected fields, and decision timestamps.

入力 [#入力-1]

| パラメータ       | 型      | 必須 | 説明                                         |
| ----------- | ------ | -- | ------------------------------------------ |
| `apiKey`    | string | はい | Persona API key                            |
| `inquiryId` | string | はい | Inquiry ID to retrieve (starts with inq\_) |

出力 [#出力-1]

| パラメータ     | 型      | 説明                    |
| --------- | ------ | --------------------- |
| `inquiry` | object | The retrieved inquiry |

persona_list_inquiries [#persona_list_inquiries]

List identity verification inquiries, optionally filtered by status, account ID, reference ID, or creation date range. Results are cursor-paginated.

入力 [#入力-2]

| パラメータ            | 型      | 必須  | 説明                                                                                                         |
| ---------------- | ------ | --- | ---------------------------------------------------------------------------------------------------------- |
| `apiKey`         | string | はい  | Persona API key                                                                                            |
| `status`         | string | いいえ | Filter by inquiry status (created, pending, completed, failed, expired, needs\_review, approved, declined) |
| `accountId`      | string | いいえ | Filter by account ID (starts with act\_); comma-separate multiple IDs                                      |
| `referenceId`    | string | いいえ | Filter by reference ID                                                                                     |
| `createdAtStart` | string | いいえ | Filter to inquiries created at or after this ISO 8601 timestamp                                            |
| `createdAtEnd`   | string | いいえ | Filter to inquiries created at or before this ISO 8601 timestamp                                           |
