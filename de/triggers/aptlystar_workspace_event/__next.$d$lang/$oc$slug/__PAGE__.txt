Triggers [#triggers]

AptlyStar Workspace Events [#aptlystar-workspace-events]

Trigger workflows from workspace run events and alert rules

Configuration [#configuration]

| Parameter      | Type    | Required | Description         |
| -------------- | ------- | -------- | ------------------- |
| `allWorkflows` | boolean | No       | Watch all workflows |
| `workflowIds`  | string  | No       | Workflow IDs        |
| `alertRule`    | string  | No       | Alert rule          |
