The Workspace Event trigger reacts to run activity inside your workspace without exposing a public webhook URL. Use it to chain automation when workflows fail, when failure rates spike, or when watched workflows go quiet.

How it works [#how-it-works]

1. Add the **Workspace Event** block as your workflow trigger.
2. Choose whether to watch all workflows or specific workflow IDs.
3. Select an alert rule.
4. Deploy the workflow — AptlyStar registers an internal subscription (HTTP deliveries to this trigger are rejected).

After each run completes, AptlyStar evaluates subscriptions in the same workspace. Matching rules queue the target workflow through the internal webhook executor.

**No activity** rules are evaluated on the inactivity polling schedule (same cron job as workspace notification inactivity checks).

Alert rules [#alert-rules]

| Rule                     | When it fires                                                       |
| ------------------------ | ------------------------------------------------------------------- |
| **Any failed run**       | Immediately after a watched workflow finishes with an error         |
| **Failure rate**         | Error rate exceeds the default threshold over the rolling window    |
| **Consecutive failures** | Watched workflow fails repeatedly in a row                          |
| **No activity**          | None of the watched workflows have run within the inactivity window |

Alert rules respect a cooldown period to prevent repeated triggers.

Configuration [#configuration]

| Parameter      | Type    | Required | Description                                                                      |
| -------------- | ------- | -------- | -------------------------------------------------------------------------------- |
| `allWorkflows` | boolean | No       | Watch every deployed workflow in the workspace                                   |
| `workflowIds`  | string  | No       | Comma-separated workflow IDs when not watching all workflows                     |
| `alertRule`    | string  | Yes      | One of `execution_failed`, `failure_rate`, `consecutive_failures`, `no_activity` |

Output [#output]

| Parameter          | Type   | Description                                             |
| ------------------ | ------ | ------------------------------------------------------- |
| `event`            | string | Event name (for example `workflow.execution.completed`) |
| `sourceWorkflowId` | string | Workflow that emitted the event                         |
| `executionId`      | string | Source run ID                                           |
| `status`           | string | Source run status                                       |
| `trigger`          | string | Source trigger type                                     |
| `durationMs`       | number | Source run duration in milliseconds                     |
| `cost`             | number | Source run cost total                                   |
