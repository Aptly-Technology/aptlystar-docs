attio_list_records [#attio_list_records]

Query and list records for a given object type (e.g. people, companies)

Eingabe [#eingabe]

| Parameter    | Typ    | Erforderlich | Beschreibung                                                                |
| ------------ | ------ | ------------ | --------------------------------------------------------------------------- |
| `objectType` | string | Ja           | The object type slug (e.g. people, companies)                               |

| `sorts`      | string | Nein         | JSON array of sort objects, e.g. \[\{"direction":"asc","attribute":"name"}] |
