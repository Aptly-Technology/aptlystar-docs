Wiza

Find, enrich, and verify B2B contact data with Wiza

Nutzungsanweisungen

Integrates Wiza into the workflow. Search prospects, enrich companies, reveal verified emails and phone numbers for individuals, and check your account credit balance.

Tools

wiza_prospect_search

Search Wiza

Eingabe

ParameterTypErforderlichBeschreibung
apiKeystringJaWiza API key
sizenumberNeinNumber of sample profiles to return (0-30, default 0)
filtersobjectNeinFull filters object (overrides individual filter params if provided)
first_namearrayNeinExact first names to match (e.g., ["John", "Jane"])
last_namearrayNeinExact last names to match
job_titlearrayNeinJob titles to include/exclude (e.g., [{"v":"CEO","s":"i"},{"v":"CTO","s":"e"}])
job_title_levelarrayNeinSeniority levels (e.g., ["cxo", "director", "manager"])
job_rolearrayNeinJob role categories (e.g., ["sales", "engineering", "marketing"])
job_sub_rolearrayNeinDetailed role categories (e.g., ["software", "product"])
locationarrayNeinPerson's location filters (city/state/country with include/exclude)
skillarrayNeinProfessional skills (e.g., ["python", "marketing"])
schoolarrayNeinEducational institutions
majorarrayNeinField of study
linkedin_slugarrayNeinLinkedIn profile slugs
job_companyarrayNeinCurrent company filters (include/exclude)
past_companyarrayNeinPast company filters
company_locationarrayNeinCompany HQ location filters
company_industryarrayNeinCompany industry filters (include/exclude)
company_sizearrayNeinCompany headcount brackets (e.g., ["1-10", "11-50", "51-200"])
company_typearrayNeinCompany type (e.g., ["private", "public", "educational"])

Ausgabe

ParameterTypBeschreibung
totalnumberTotal number of matching prospects
profilesarraySample profiles matching the filter criteria

wiza_individual_reveal

Reveal a contact via LinkedIn URL, name + company/domain, or email. Starts the reveal and polls until it resolves. Uses 2 credits per valid email and 5 credits per phone, charged only on success.

emailstringNeinEmail address (use alone or with other identifiers)
accept_workbooleanNeinWhether to accept work emails (email_options)
