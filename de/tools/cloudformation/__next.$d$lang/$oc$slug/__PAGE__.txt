Nutzungsanweisungen [#nutzungsanweisungen]

Integrate AWS CloudFormation into workflows. Describe stacks, list resources, detect drift, view stack events, retrieve templates, and validate templates. Requires AWS access key and secret access key.

Tools [#tools]

cloudformation_describe_stacks [#cloudformation_describe_stacks]

List and describe CloudFormation stacks

Eingabe [#eingabe]

| Parameter            | Typ    | Erforderlich | Beschreibung                                           |
| -------------------- | ------ | ------------ | ------------------------------------------------------ |
| `awsRegion`          | string | Ja           | AWS region (e.g., us-east-1)                           |
| `awsAccessKeyId`     | string | Ja           | AWS access key ID                                      |
| `awsSecretAccessKey` | string | Ja           | AWS secret access key                                  |
| `stackName`          | string | Nein         | Stack name or ID to describe (omit to list all stacks) |

Ausgabe [#ausgabe]

| Parameter | Typ   | Beschreibung                                                 |
| --------- | ----- | ------------------------------------------------------------ |
