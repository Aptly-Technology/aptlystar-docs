Nutzungsanweisungen [#nutzungsanweisungen]

Integrate Workday HRIS into your workflow. Create pre-hires, hire employees, manage worker profiles, assign onboarding plans, handle job changes, retrieve compensation data, and process terminations.

Tools [#tools]

workday_get_worker [#workday_get_worker]

Retrieve a specific worker profile including personal, employment, and organization data.

Eingabe [#eingabe]

| Parameter   | Typ    | Erforderlich | Beschreibung                                                                                                      |
| ----------- | ------ | ------------ | ----------------------------------------------------------------------------------------------------------------- |
| `tenantUrl` | string | Ja           | Workday instance URL (e.g., [https://wd5-impl-services1.workday.com\\](https://wd5-impl-services1.workday.com\\)) |
| `tenant`    | string | Ja           | Workday tenant name                                                                                               |
| `username`  | string | Ja           | Integration System User username                                                                                  |
| `password`  | string | Ja           | Integration System User password                                                                                  |
| `workerId`  | string | Ja           | Worker ID to retrieve (e.g., 3aa5550b7fe348b98d7b5741afc65534)                                                    |

Ausgabe [#ausgabe]

| Parameter | Typ  | Beschreibung                                                    |
| --------- | ---- | --------------------------------------------------------------- |
| `worker`  | json | Worker profile with personal, employment, and organization data |
