sts_assume_role [#sts_assume_role]

Assume an IAM role and receive temporary security credentials

Eingabe [#eingabe]

| Parameter         | Typ    | Erforderlich | Beschreibung                                                             |
| ----------------- | ------ | ------------ | ------------------------------------------------------------------------ |
| `region`          | string | Ja           | AWS region (e.g., us-east-1)                                             |
| `accessKeyId`     | string | Ja           | AWS access key ID                                                        |
| `secretAccessKey` | string | Ja           | AWS secret access key                                                    |
| `roleArn`         | string | Ja           | ARN of the IAM role to assume                                            |
| `roleSessionName` | string | Ja           | Identifier for the assumed role session                                  |
| `durationSeconds` | number | Nein         | Duration of the session in seconds (900-43200, default 3600)             |
| `policy`          | string | Nein         | JSON IAM policy to further restrict session permissions (max 2048 chars) |
| `externalId`      | string | Nein         | External ID for cross-account access                                     |
| `serialNumber`    | string | Nein         | MFA device serial number or ARN                                          |
| `tokenCode`       | string | Nein         | MFA token code (6 digits)                                                |

| `expiration`       | string | Credential expiration timestamp                 |
| `assumedRoleArn`   | string | ARN of the assumed role                         |
| `assumedRoleId`    | string | Assumed role ID with session name               |
| `packedPolicySize` | number | Percentage of allowed policy size used          |
| `sourceIdentity`   | string | Source identity set on the role session, if any |
