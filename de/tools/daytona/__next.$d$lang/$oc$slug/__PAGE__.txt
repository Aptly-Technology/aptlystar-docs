Nutzungsanweisungen [#nutzungsanweisungen]

Integrate Daytona into your workflow to run AI-generated code in secure, isolated sandboxes. Create and manage sandboxes, execute shell commands, run Python, JavaScript, or TypeScript code, transfer files, and clone Git repositories.

Tools [#tools]

daytona_create_sandbox [#daytona_create_sandbox]

Create a new Daytona sandbox for running AI-generated code in isolation

Eingabe [#eingabe]

| Parameter             | Typ     | Erforderlich | Beschreibung                                                                       |
| --------------------- | ------- | ------------ | ---------------------------------------------------------------------------------- |
| `apiKey`              | string  | Ja           | Daytona API key                                                                    |
| `snapshot`            | string  | Nein         | ID or name of the snapshot to create the sandbox from (uses default if empty)      |
| `name`                | string  | Nein         | Name for the sandbox (defaults to the sandbox ID)                                  |
| `target`              | string  | Nein         | Region where the sandbox will be created (e.g., us, eu)                            |
| `user`                | string  | Nein         | User associated with the sandbox                                                   |
| `env`                 | json    | Nein         | Environment variables to set in the sandbox as key-value pairs                     |
| `labels`              | json    | Nein         | Labels to attach to the sandbox as key-value pairs                                 |
| `cpu`                 | number  | Nein         | CPU cores to allocate to the sandbox                                               |
| `memory`              | number  | Nein         | Memory to allocate to the sandbox in GB                                            |
| `disk`                | number  | Nein         | Disk space to allocate to the sandbox in GB                                        |
| `autoStopInterval`    | number  | Nein         | Auto-stop interval in minutes (0 disables auto-stop)                               |
| `autoArchiveInterval` | number  | Nein         | Auto-archive interval in minutes (0 uses the maximum interval)                     |
| `autoDeleteInterval`  | number  | Nein         | Auto-delete interval in minutes (negative disables, 0 deletes immediately on stop) |
| `public`              | boolean | Nein         | Whether the sandbox HTTP preview is publicly accessible                            |

Ausgabe [#ausgabe]

| Parameter | Typ  | Beschreibung        |
| --------- | ---- | ------------------- |
| `sandbox` | json | The created sandbox |
