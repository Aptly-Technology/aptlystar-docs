Astrax ist dein Assistent im Editor, der dir hilft, Workflows mit Aptlystar Astrax zu erstellen und zu bearbeiten sowie diese zu verstehen und zu verbessern. Er kann:

* **Erklären**: Beantwortet Fragen zu Aptlystar und deinem aktuellen Workflow
* **Anleiten**: Schlägt Bearbeitungen und Best Practices vor
* **Bearbeiten**: Nimmt Änderungen an Blöcken, Verbindungen und Einstellungen vor, wenn du zustimmst

<Callout type="info">
  Astrax ist ein von Aptlystar verwalteter Dienst. Für selbst gehostete Installationen generiere einen Astrax API-Schlüssel in der gehosteten App (aptlystar.ai → Einstellungen → Astrax)

  1. Gehe zu [aptlystar.ai](https://aptlystar.ai) → Einstellungen → Astrax und generiere einen Astrax API-Schlüssel
  2. Setze `ASTRAX_API_KEY` in deiner selbst gehosteten Umgebung auf diesen Wert
</Callout>

Kontextmenü (@) [#kontextmenü-]

Verwende das `@` Symbol, um auf verschiedene Ressourcen zu verweisen und Astrax mehr Kontext über deinen Arbeitsbereich zu geben:

Das `@` Menü bietet Zugriff auf:

* **Chats**: Verweise auf vorherige Astrax-Gespräche
* **Alle Workflows**: Verweise auf beliebige Workflows in deinem Arbeitsbereich
* **Workflow-Blöcke**: Verweise auf bestimmte Blöcke aus Workflows
* **Blöcke**: Verweise auf Blocktypen und Vorlagen
* **Wissen**: Verweise auf deine hochgeladenen Dokumente und Wissensdatenbank
* **Dokumentation**: Verweise auf Aptlystar-Dokumentation
* **Vorlagen**: Verweise auf Workflow-Vorlagen
* **Logs**: Verweise auf Ausführungsprotokolle und Ergebnisse

Diese kontextbezogenen Informationen helfen Astrax, genauere und relevantere Unterstützung für deinen spezifischen Anwendungsfall zu bieten.

Modusauswahl-Oberfläche [#modusauswahl-oberfläche]

Du kannst einfach zwischen verschiedenen Denkmodi über die Modusauswahl in der Astrax-Oberfläche wechseln:

Die Oberfläche ermöglicht dir:

* **Denkebene auswählen**: Wähle zwischen Schnell, Auto, Erweitert oder Behemoth
* **MAX-Modus aktivieren**: Umschalten für maximale Denkfähigkeiten, wenn du die gründlichste Analyse benötigst
* **Modusbeschreibungen anzeigen**: Verstehe, wofür jeder Modus optimiert ist

Wähle deinen Modus basierend auf der Komplexität deiner Aufgabe - verwende Schnell für einfache Fragen und Behemoth für komplexe architektonische Änderungen.

Abrechnung und Kostenberechnung [#abrechnung-und-kostenberechnung]

Wie Kosten berechnet werden [#wie-kosten-berechnet-werden]

Die Astrax-Nutzung wird pro Token vom zugrundeliegenden LLM abgerechnet:

* **Eingabe-Tokens**: werden zum Basispreis des Anbieters berechnet (**zum Selbstkostenpreis**)
* **Ausgabe-Tokens**: werden mit dem **1,5-fachen** des Basis-Ausgabepreises des Anbieters berechnet

```javascript
astraxCost = (inputTokens × inputPrice + outputTokens × (outputPrice × 1.5)) / 1,000,000
```

| Komponente | Angewendeter Tarif |
| ---------- | ------------------ |
| Eingabe    | inputPrice         |
| Ausgabe    | outputPrice × 1,5  |

<Callout type="warning">
  Die angezeigten Preise spiegeln die Tarife vom 4. September 2025 wider. Überprüfen Sie die Anbieter-Dokumentation für aktuelle Preise.
</Callout>

<Callout type="info">
  Modellpreise werden pro Million Tokens angegeben. Die Berechnung teilt durch 1.000.000, um die tatsächlichen Kosten zu ermitteln. Siehe <a href="/execution/costs">die Seite zur Kostenberechnung</a> für Hintergründe und Beispiele.
</Callout>

Fahre mit der Maus über eine deiner Nachrichten und klicke auf **Bearbeiten**, um sie zu ändern und erneut zu senden. Dies ist nützlich, um deine Eingaben zu verfeinern.

Nachrichtenwarteschlange [#nachrichtenwarteschlange]

Wenn du eine Nachricht sendest, während Astrax noch antwortet, wird sie in die Warteschlange gestellt. Du kannst:

* Warteschlangennachrichten im erweiterbaren Warteschlangenpanel anzeigen
* Eine Nachricht aus der Warteschlange sofort senden (bricht die aktuelle Antwort ab)
* Nachrichten aus der Warteschlange entfernen

Dateianhänge [#dateianhänge]

Klicke auf das Anhang-Symbol, um Dateien mit deiner Nachricht hochzuladen. Unterstützte Dateitypen umfassen:

* Bilder (Vorschau-Thumbnails werden angezeigt)
* PDFs
* Textdateien, JSON, XML
* Andere Dokumentformate

Dateien werden als anklickbare Thumbnails angezeigt, die in einem neuen Tab geöffnet werden.

Checkpoints & Änderungen [#checkpoints--änderungen]

Wenn Astrax Änderungen an deinem Workflow vornimmt, speichert es Checkpoints, damit du bei Bedarf zurückkehren kannst.

Checkpoints anzeigen [#checkpoints-anzeigen]

Fahre mit der Maus über eine Astrax-Nachricht und klicke auf das Checkpoints-Symbol, um gespeicherte Workflow-Zustände für diese Nachricht anzuzeigen.

Änderungen rückgängig machen [#änderungen-rückgängig-machen]

Klicke bei jedem Checkpoint auf **Rückgängig machen**, um deinen Workflow auf diesen Zustand zurückzusetzen. Ein Bestätigungsdialog warnt dich, dass diese Aktion nicht rückgängig gemacht werden kann.

Änderungen akzeptieren [#änderungen-akzeptieren]

Wenn Astrax Änderungen vorschlägt, kannst du:

* **Akzeptieren**: Die vorgeschlagenen Änderungen anwenden (`Mod+Shift+Enter`)
* **Ablehnen**: Die Änderungen verwerfen und deinen aktuellen Workflow beibehalten

Denkblöcke [#denkblöcke]

Bei komplexen Anfragen kann Astrax seinen Denkprozess in erweiterbaren Denkblöcken anzeigen:

* Blöcke werden automatisch erweitert, während Astrax denkt
* Klicken zum manuellen Erweitern/Reduzieren
* Zeigt die Dauer des Denkprozesses an
* Hilft dir zu verstehen, wie Astrax zu seiner Lösung gekommen ist

Optionsauswahl [#optionsauswahl]

Wenn Astrax mehrere Optionen präsentiert, kannst du auswählen mit:

| Steuerung             | Aktion                          |
| --------------------- | ------------------------------- |
| **1-9**               | Option nach Nummer auswählen    |
| **Pfeiltaste auf/ab** | Zwischen Optionen navigieren    |
| **Eingabetaste**      | Hervorgehobene Option auswählen |

Ausgewählte Optionen sind hervorgehoben; nicht ausgewählte Optionen erscheinen durchgestrichen.

Tastenkombinationen [#tastenkombinationen]

| Tastenkombination | Aktion                        |
| ----------------- | ----------------------------- |
| `@`               | Kontextmenü öffnen            |
| `/`               | Slash-Befehle öffnen          |
| `Arrow Up/Down`   | Menüelemente navigieren       |
| `Enter`           | Menüelement auswählen         |
| `Esc`             | Menüs schließen               |
| `Mod+Shift+Enter` | Astrax-Änderungen akzeptieren |

Nutzungslimits [#nutzungslimits]

Die Astrax-Nutzung wird pro Token des zugrunde liegenden LLM abgerechnet. Wenn Sie Ihr Nutzungslimit erreichen, fordert Astrax Sie auf, Ihr Limit zu erhöhen. Sie können die Nutzung in Schritten (50 $, 100 $) von Ihrer aktuellen Basis aus hinzufügen.

<Callout type="info">
  Siehe die [Seite zur Kostenberechnung](/execution/costs) für Abrechnungsdetails.
</Callout>

Astrax MCP [#astrax-mcp]

Sie können Astrax als MCP-Server in Ihrem bevorzugten Editor oder AI-Client verwenden. Damit können Sie Aptlystar-Workflows direkt aus Tools wie Cursor, Claude Code, Claude Desktop und VS Code erstellen, testen, bereitstellen und verwalten.

Generieren eines Astrax-API-Schlüssels [#generieren-eines-astrax-api-schlüssels]

Um sich mit dem Astrax-MCP-Server zu verbinden, benötigen Sie einen **Astrax-API-Schlüssel**:

1. Gehen Sie zu [aptlystar.ai](https://aptlystar.ai) und melden Sie sich an
2. Navigieren Sie zu **Einstellungen** → **Astrax**
3. Klicken Sie auf **API-Schlüssel generieren**
4. Kopieren Sie den Schlüssel – er wird nur einmal angezeigt

Der Schlüssel sieht aus wie `sk-aptlystar-astrax-...`. Sie werden ihn in der folgenden Konfiguration verwenden.

Cursor [#cursor]

Fügen Sie Folgendes zu Ihrer `.cursor/mcp.json` (Projektebene) oder den globalen Cursor-MCP-Einstellungen hinzu:

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "url": "https://www.aptlystar.ai/api/mcp/astrax",
      "headers": {
        "X-API-Key": "YOUR_ASTRAX_API_KEY"
      }
    }
  }
}
```

Ersetzen Sie `YOUR_ASTRAX_API_KEY` durch den oben generierten Schlüssel.

Claude Code [#claude-code]

Führen Sie den folgenden Befehl aus, um den Astrax MCP-Server hinzuzufügen:

```bash
claude mcp add aptlystar-astrax \
  --transport http \
  https://www.aptlystar.ai/api/mcp/astrax \
  --header "X-API-Key: YOUR_ASTRAX_API_KEY"
```

Ersetzen Sie `YOUR_ASTRAX_API_KEY` durch Ihren Schlüssel.

Claude Desktop [#claude-desktop]

Claude Desktop benötigt [`mcp-remote`](https://www.npmjs.com/package/mcp-remote), um sich mit HTTP-basierten MCP-Servern zu verbinden. Fügen Sie Folgendes zu Ihrer Claude Desktop-Konfigurationsdatei hinzu (`~/Library/Application Support/Claude/claude_desktop_config.json` unter macOS):

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.aptlystar.ai/api/mcp/astrax",
        "--header",
        "X-API-Key: YOUR_ASTRAX_API_KEY"
      ]
    }
  }
}
```

Ersetzen Sie `YOUR_ASTRAX_API_KEY` durch Ihren Schlüssel.

VS Code [#vs-code]

Fügen Sie Folgendes zu Ihrer VS Code `settings.json` oder Workspace `.vscode/settings.json` hinzu:

```json
{
  "mcp": {
    "servers": {
      "aptlystar-astrax": {
        "type": "http",
        "url": "https://www.aptlystar.ai/api/mcp/astrax",
        "headers": {
          "X-API-Key": "YOUR_ASTRAX_API_KEY"
        }
      }
    }
  }
}
```

Ersetzen Sie `YOUR_ASTRAX_API_KEY` durch Ihren Schlüssel.

  Für selbst gehostete Deployments ersetzen Sie `https://www.aptlystar.ai` durch Ihre selbst gehostete Aptlystar-URL.
