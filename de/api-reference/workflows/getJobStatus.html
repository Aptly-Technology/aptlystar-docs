Get Job Status

Poll the status of an asynchronous workflow execution. Use the jobId returned from the Execute Workflow endpoint when the execution is queued asynchronously.

GET/api/jobs/{jobId}

Authorization

apiKey
X-API-Key<token>

Your Aptlystar API key (personal or workspace). Generate one from the Aptlystar dashboard under Settings > API Keys.

In: header

Path Parameters

jobId*string

The job identifier returned in the async execution response.

Response Body

application/json
