`GET /api/v1/workflows`

## Description
Retrieve all workflows in a workspace with cursor-based pagination.

## Parameters

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.

- **folderId** (query) — `string`: Filter results to only include workflows within this folder.

- **deployedOnly** (query) — `boolean`: When true, only return workflows that have been deployed. Useful for listing workflows available for API execution.

- **limit** (query) — `integer`: Maximum number of workflows to return per page. Must be between 1 and 100.

- **cursor** (query) — `string`: Pagination cursor returned from a previous request's nextCursor field. Omit for the first page.
