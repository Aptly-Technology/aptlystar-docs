Trigger workflow when an email bounces

Configuration [#configuration]

| Parameter    | Type           | Required | Description                                         |
| ------------ | -------------- | -------- | --------------------------------------------------- |
| `apiKey`     | api-key-picker | Yes      | Required to create the webhook in Lemlist.          |
