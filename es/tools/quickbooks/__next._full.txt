Instrucciones de uso [#instrucciones-de-uso]

Connect to QuickBooks Online to read and write customers, invoices, and chart-of-accounts entries, or run arbitrary QuickBooks queries. Uses Intuit OAuth 2.0; the company (realmId) is captured from the OAuth callback at sign-in time.

Herramientas [#herramientas]

quickbooks_create_bill [#quickbooks_create_bill]

Create a new bill (vendor expense) in QuickBooks Online

Entrada [#entrada]

| Parámetro  | Tipo   | Obligatorio | Descripción                                                                    |
| ---------- | ------ | ----------- | ------------------------------------------------------------------------------ |
| `realmId`  | string | Sí          | QuickBooks company ID (realmId) — captured at OAuth time                       |
| `vendorId` | string | Sí          | Vendor ID for the bill                                                         |
| `lines`    | json   | Sí          | Bill line items (JSON array). Each entry: \{ amount, accountId, description? } |
| `txnDate`  | string | No          | Transaction date (YYYY-MM-DD)                                                  |
