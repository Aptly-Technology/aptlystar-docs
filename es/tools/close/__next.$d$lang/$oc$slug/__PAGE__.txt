Instrucciones de uso [#instrucciones-de-uso]

Connect to Close CRM to list leads, retrieve contacts, and query opportunities. Filter by search query or status, and paginate through large result sets.

Herramientas [#herramientas]

close_list_leads [#close_list_leads]

Retrieve leads from Close CRM

Entrada [#entrada]

| Parámetro | Tipo   | Obligatorio | Descripción                                            |
| --------- | ------ | ----------- | ------------------------------------------------------ |
| `apiKey`  | string | Sí          | Close CRM API key                                      |
| `query`   | string | No          | Search query to filter leads (e.g. "company:Acme")     |
| `limit`   | number | No          | Maximum number of leads to return (1–200, default 100) |
| `skip`    | number | No          | Number of leads to skip for pagination (default 0)     |

Salida [#salida]

| Parámetro      | Tipo    | Descripción                               |
| -------------- | ------- | ----------------------------------------- |
| `leads`        | array   | Array of Close CRM lead objects           |
| `totalResults` | number  | Total number of matching leads            |
| `hasMore`      | boolean | Whether more leads are available to fetch |

close_get_contacts [#close_get_contacts]

Retrieve contacts from Close CRM with pagination support

Entrada [#entrada-1]

| Parámetro | Tipo   | Obligatorio | Descripción                                               |
| --------- | ------ | ----------- | --------------------------------------------------------- |
| `apiKey`  | string | Sí          | Close CRM API key                                         |
| `limit`   | number | No          | Maximum number of contacts to return (1–200, default 100) |
| `skip`    | number | No          | Number of contacts to skip for pagination (default 0)     |

Salida [#salida-1]

| Parámetro      | Tipo    | Descripción                                  |
| -------------- | ------- | -------------------------------------------- |
| `contacts`     | array   | Array of Close CRM contact objects           |
| `totalResults` | number  | Total number of contacts                     |
| `hasMore`      | boolean | Whether more contacts are available to fetch |

close_get_opportunities [#close_get_opportunities]

Retrieve opportunities (deals) from Close CRM, filterable by status

Entrada [#entrada-2]

| Parámetro    | Tipo   | Obligatorio | Descripción                                                    |
| ------------ | ------ | ----------- | -------------------------------------------------------------- |
| `apiKey`     | string | Sí          | Close CRM API key                                              |
| `statusType` | string | No          | Filter by status: "active", "won", or "lost"                   |
| `limit`      | number | No          | Maximum number of opportunities to return (1–200, default 100) |
| `skip`       | number | No          | Number of opportunities to skip for pagination (default 0)     |

Salida [#salida-2]

| Parámetro       | Tipo    | Descripción                                       |
| --------------- | ------- | ------------------------------------------------- |
| `opportunities` | array   | Array of Close CRM opportunity objects            |
| `totalResults`  | number  | Total number of matching opportunities            |
| `hasMore`       | boolean | Whether more opportunities are available to fetch |
