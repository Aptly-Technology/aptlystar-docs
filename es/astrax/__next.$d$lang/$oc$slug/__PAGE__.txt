Astrax es tu asistente integrado en el editor que te ayuda a crear y editar flujos de trabajo con Aptlystar Astrax, así como a entenderlos y mejorarlos. Puede:

* **Explicar**: Responder preguntas sobre Aptlystar y tu flujo de trabajo actual
* **Guiar**: Sugerir ediciones y mejores prácticas
* **Editar**: Realizar cambios en bloques, conexiones y configuraciones cuando los apruebes

<Callout type="info">
  Astrax es un servicio gestionado por Aptlystar. Para implementaciones autoalojadas, genera una clave API de Astrax en la aplicación alojada (aptlystar.ai → Configuración → Astrax)

  1. Ve a [aptlystar.ai](https://aptlystar.ai) → Configuración → Astrax y genera una clave API de Astrax
  2. Establece `ASTRAX_API_KEY` en tu entorno autoalojado con ese valor
</Callout>

Menú contextual (@) [#menú-contextual-]

Usa el símbolo `@` para hacer referencia a varios recursos y proporcionar a Astrax más contexto sobre tu espacio de trabajo:

El menú `@` proporciona acceso a:

* **Chats**: Referencia conversaciones previas con astrax
* **Todos los flujos de trabajo**: Referencia cualquier flujo de trabajo en tu espacio de trabajo
* **Bloques de flujo de trabajo**: Referencia bloques específicos de los flujos de trabajo
* **Bloques**: Referencia tipos de bloques y plantillas
* **Conocimiento**: Referencia tus documentos subidos y base de conocimientos
* **Documentación**: Referencia la documentación de Aptlystar
* **Plantillas**: Referencia plantillas de flujo de trabajo
* **Registros**: Referencia registros de ejecución y resultados

Esta información contextual ayuda a Astrax a proporcionar asistencia más precisa y relevante para tu caso de uso específico.

Interfaz de selección de modo [#interfaz-de-selección-de-modo]

Elige tu modo según la complejidad de tu tarea - usa Rápido para preguntas simples y Behemoth para cambios arquitectónicos complejos.

Facturación y cálculo de costos [#facturación-y-cálculo-de-costos]

Cómo se calculan los costos [#cómo-se-calculan-los-costos]

El uso de Astrax se factura por token del LLM subyacente:

* **Tokens de entrada**: facturados a la tarifa base del proveedor (**a costo**)
* **Tokens de salida**: facturados a **1,5×** la tarifa base de salida del proveedor

```javascript
astraxCost = (inputTokens × inputPrice + outputTokens × (outputPrice × 1.5)) / 1,000,000
```

| Componente | Tarifa aplicada   |
| ---------- | ----------------- |
| Entrada    | inputPrice        |
| Salida     | outputPrice × 1,5 |

<Callout type="warning">
  Los precios mostrados reflejan las tarifas a partir del 4 de septiembre de 2025. Consulta la documentación del proveedor para conocer los precios actuales.
</Callout>

<Callout type="info">
  Los precios de los modelos son por millón de tokens. El cálculo divide por 1.000.000 para obtener el costo real. Consulta <a href="/execution/costs">la página de Cálculo de Costos</a> para obtener información general y ejemplos.
</Callout>

* Enviar un mensaje en cola inmediatamente (interrumpe la respuesta actual)
* Eliminar mensajes de la cola

Archivos adjuntos [#archivos-adjuntos]

Haz clic en el icono de adjunto para subir archivos con tu mensaje. Los tipos de archivo compatibles incluyen:

* Imágenes (se muestran miniaturas de vista previa)
* PDFs
* Archivos de texto, JSON, XML
* Otros formatos de documentos

Los archivos se muestran como miniaturas en las que se puede hacer clic y que se abren en una nueva pestaña.

Puntos de control y cambios [#puntos-de-control-y-cambios]

Cuando Astrax realiza cambios en tu flujo de trabajo, guarda puntos de control para que puedas revertirlos si es necesario.

Ver puntos de control [#ver-puntos-de-control]

Pasa el cursor sobre un mensaje de Astrax y haz clic en el icono de puntos de control para ver los estados guardados del flujo de trabajo para ese mensaje.

Revertir cambios [#revertir-cambios]

Haz clic en **Revertir** en cualquier punto de control para restaurar tu flujo de trabajo a ese estado. Un diálogo de confirmación te advertirá que esta acción no se puede deshacer.

Aceptar cambios [#aceptar-cambios]

Cuando Astrax propone cambios, puedes:

* **Aceptar**: aplicar los cambios propuestos (`Mod+Shift+Enter`)
* **Rechazar**: descartar los cambios y mantener tu flujo de trabajo actual

Bloques de pensamiento [#bloques-de-pensamiento]

Para solicitudes complejas, Astrax puede mostrar su proceso de razonamiento en bloques de pensamiento expandibles:

* Los bloques se expanden automáticamente mientras Astrax está pensando
* Haz clic para expandir/contraer manualmente
* Muestra la duración del proceso de pensamiento
* Te ayuda a entender cómo Astrax llegó a su solución

Selección de opciones [#selección-de-opciones]

Cuando Astrax presenta múltiples opciones, puedes seleccionar usando:

| Control                 | Acción                        |
| ----------------------- | ----------------------------- |
| **1-9**                 | Seleccionar opción por número |
| **Flecha arriba/abajo** | Navegar entre opciones        |
| **Enter**               | Seleccionar opción resaltada  |

Las opciones seleccionadas están resaltadas; las opciones no seleccionadas aparecen tachadas.

Atajos de teclado [#atajos-de-teclado]

| Atajo             | Acción                        |
| ----------------- | ----------------------------- |
| `@`               | Abrir menú contextual         |
| `/`               | Abrir comandos de barra       |
| `Arrow Up/Down`   | Navegar elementos del menú    |
| `Enter`           | Seleccionar elemento del menú |
| `Esc`             | Cerrar menús                  |
| `Mod+Shift+Enter` | Aceptar cambios de Astrax     |

Límites de uso [#límites-de-uso]

El uso de Astrax se factura por token del LLM subyacente. Si alcanzas tu límite de uso, Astrax te pedirá que aumentes tu límite. Puedes agregar uso en incrementos ($50, $100) desde tu base actual.

  Consulta la [página de cálculo de costos](/execution/costs) para detalles de facturación.
</Callout>

Astrax MCP [#astrax-mcp]

Puedes usar Astrax como servidor MCP en tu editor o cliente de IA favorito. Esto te permite construir, probar, desplegar y gestionar flujos de trabajo de Aptlystar directamente desde herramientas como Cursor, Claude Code, Claude Desktop y VS Code.

Generar una clave API de Astrax [#generar-una-clave-api-de-astrax]

Para conectarte al servidor MCP de Astrax, necesitas una **clave API de Astrax**:

1. Ve a [aptlystar.ai](https://aptlystar.ai) e inicia sesión
2. Navega a **Configuración** → **Astrax**
3. Haz clic en **Generar clave API**
4. Copia la clave — solo se muestra una vez

La clave se verá como `sk-aptlystar-astrax-...`. Usarás esto en la configuración a continuación.

Cursor [#cursor]

Agrega lo siguiente a tu `.cursor/mcp.json` (nivel de proyecto) o configuración global de MCP de Cursor:

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "url": "https://www.aptlystar.ai/api/mcp/astrax",
      "headers": {
        "X-API-Key": "YOUR_ASTRAX_API_KEY"
      }
    }
  }
}
```

Reemplaza `YOUR_ASTRAX_API_KEY` con la clave que generaste anteriormente.

Claude Code [#claude-code]

Ejecuta el siguiente comando para añadir el servidor MCP de Astrax:

```bash
claude mcp add aptlystar-astrax \
  --transport http \
  https://www.aptlystar.ai/api/mcp/astrax \
  --header "X-API-Key: YOUR_ASTRAX_API_KEY"
```

Reemplaza `YOUR_ASTRAX_API_KEY` con tu clave.

Claude Desktop [#claude-desktop]

Claude Desktop requiere [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) para conectarse a servidores MCP basados en HTTP. Añade lo siguiente a tu archivo de configuración de Claude Desktop (`~/Library/Application Support/Claude/claude_desktop_config.json` en macOS):

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.aptlystar.ai/api/mcp/astrax",
        "--header",
        "X-API-Key: YOUR_ASTRAX_API_KEY"
      ]
    }
  }
}
```

Reemplaza `YOUR_ASTRAX_API_KEY` con tu clave.

VS Code [#vs-code]

Añade lo siguiente a tu `settings.json` de VS Code o al `.vscode/settings.json` del espacio de trabajo:

```json
{
  "mcp": {
    "servers": {
      "aptlystar-astrax": {
        "type": "http",
        "url": "https://www.aptlystar.ai/api/mcp/astrax",
        "headers": {
          "X-API-Key": "YOUR_ASTRAX_API_KEY"
        }
      }
    }
  }
}
```

Reemplaza `YOUR_ASTRAX_API_KEY` con tu clave.

  Para implementaciones auto-alojadas, reemplaza `https://www.aptlystar.ai` con tu URL de Aptlystar auto-alojada.
