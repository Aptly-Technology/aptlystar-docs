`DELETE /api/v1/tables/{tableId}/columns`

## Description
Delete a column from the table schema. This removes the column definition and strips the corresponding key from all existing row data. Cannot delete the last remaining column.

## Parameters

- **tableId** (path) (required) — `string`: The unique identifier of the table.

## Request Body

```json
{
  "type": "object",
  "required": [
    "workspaceId",
    "columnName"
  ],
  "properties": {
    "workspaceId": {
      "type": "string",
      "description": "The workspace ID"
    },
    "columnName": {
      "type": "string",
      "description": "Name of the column to delete"
    }
  }
}
```
