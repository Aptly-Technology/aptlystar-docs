`POST /api/workflows/{id}/executions/{executionId}/cancel`

## Description
Cancel a running workflow execution. Only effective for executions that are still in progress.

## Parameters

- **id** (path) (required) — `string`: The unique identifier of the workflow.

- **executionId** (path) (required) — `string`: The unique identifier of the execution to cancel.

## Responses

### 200 — Execution was successfully cancelled.

```json
{
  "type": "object",
  "properties": {
    "success": {
      "type": "boolean",
      "description": "Whether the cancellation was successful."
    },
    "executionId": {
      "type": "string",
      "description": "The ID of the cancelled execution."
    }
  }
}
```

### 401 — Invalid or missing API key. Ensure the X-API-Key header is set with a valid key.

```json
{
  "type": "object",
  "properties": {
    "error": {
      "type": "string",
      "description": "Human-readable error message."
    }
  }
}
```

{

  }
