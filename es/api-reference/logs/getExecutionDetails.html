Get Execution Details

Retrieve the full execution state snapshot, including the workflow state at time of execution and detailed metadata.

GET/api/v1/logs/executions/{executionId}

Authorization

apiKey
X-API-Key<token>

Your Aptlystar API key (personal or workspace). Generate one from the Aptlystar dashboard under Settings > API Keys.

In: header

Path Parameters

executionId*string

The unique execution identifier.

Response Body

application/json
