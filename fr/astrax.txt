Astrax est votre assistant intégré à l'éditeur qui vous aide à créer et à modifier des flux de travail avec Aptlystar Astrax, ainsi qu'à les comprendre et à les améliorer. Il peut :

* **Expliquer** : répondre aux questions sur Aptlystar et votre flux de travail actuel
* **Guider** : suggérer des modifications et des bonnes pratiques
* **Modifier** : apporter des changements aux blocs, connexions et paramètres lorsque vous les approuvez

<Callout type="info">
  Astrax est un service géré par Aptlystar. Pour les déploiements auto-hébergés, générez une clé API Astrax dans l'application hébergée (aptlystar.ai → Paramètres → Astrax)

  1. Allez sur [aptlystar.ai](https://aptlystar.ai) → Paramètres → Astrax et générez une clé API Astrax
  2. Définissez `ASTRAX_API_KEY` dans votre environnement auto-hébergé avec cette valeur
</Callout>

* **Tous les flux de travail** : référencer n'importe quel flux de travail dans votre espace de travail

Facturation et calcul des coûts [#facturation-et-calcul-des-coûts]

Comment les coûts sont calculés [#comment-les-coûts-sont-calculés]

L'utilisation de Astrax est facturée par token à partir du LLM sous-jacent :

* **Tokens d'entrée** : facturés au tarif de base du fournisseur (**au prix coûtant**)
* **Tokens de sortie** : facturés à **1,5×** le tarif de base de sortie du fournisseur

```javascript
astraxCost = (inputTokens × inputPrice + outputTokens × (outputPrice × 1.5)) / 1,000,000
```

| Composant | Tarif appliqué    |
| --------- | ----------------- |
| Entrée    | inputPrice        |
| Sortie    | outputPrice × 1,5 |

<Callout type="warning">
  Les prix indiqués reflètent les tarifs en date du 4 septembre 2025. Consultez la documentation du fournisseur pour les tarifs actuels.
</Callout>

<Callout type="info">
  Les prix des modèles sont par million de tokens. Le calcul divise par 1 000 000 pour obtenir le coût réel. Consultez <a href="/execution/costs">la page de calcul des coûts</a> pour plus d'informations et des exemples.
</Callout>

Astrax MCP [#astrax-mcp]

Vous pouvez utiliser Astrax comme serveur MCP dans votre éditeur ou client IA préféré. Cela vous permet de créer, tester, déployer et gérer des workflows Aptlystar directement depuis des outils comme Cursor, Claude Code, Claude Desktop et VS Code.

Générer une clé API Astrax [#générer-une-clé-api-astrax]

Pour vous connecter au serveur MCP Astrax, vous avez besoin d'une **clé API Astrax** :

1. Rendez-vous sur [aptlystar.ai](https://aptlystar.ai) et connectez-vous
2. Accédez à **Paramètres** → **Astrax**
3. Cliquez sur **Générer une clé API**
4. Copiez la clé — elle n'est affichée qu'une seule fois

La clé ressemblera à `sk-aptlystar-astrax-...`. Vous l'utiliserez dans la configuration ci-dessous.

Cursor [#cursor]

Ajoutez ce qui suit à votre `.cursor/mcp.json` (niveau projet) ou aux paramètres MCP globaux de Cursor :

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "url": "https://www.aptlystar.ai/api/mcp/astrax",
      "headers": {
        "X-API-Key": "YOUR_ASTRAX_API_KEY"
      }
    }
  }
}
```

Remplacez `YOUR_ASTRAX_API_KEY` par la clé que vous avez générée ci-dessus.

Claude Code [#claude-code]

Exécutez la commande suivante pour ajouter le serveur MCP Astrax :

```bash
claude mcp add aptlystar-astrax \
  --transport http \
  https://www.aptlystar.ai/api/mcp/astrax \
  --header "X-API-Key: YOUR_ASTRAX_API_KEY"
```

Remplacez `YOUR_ASTRAX_API_KEY` par votre clé.

Claude Desktop [#claude-desktop]

Claude Desktop nécessite [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) pour se connecter aux serveurs MCP basés sur HTTP. Ajoutez ce qui suit à votre fichier de configuration Claude Desktop (`~/Library/Application Support/Claude/claude_desktop_config.json` sur macOS) :

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.aptlystar.ai/api/mcp/astrax",
        "--header",
        "X-API-Key: YOUR_ASTRAX_API_KEY"
      ]
    }
  }
}
```

Remplacez `YOUR_ASTRAX_API_KEY` par votre clé.

VS Code [#vs-code]

Ajoutez ce qui suit à votre `settings.json` VS Code ou à votre `.vscode/settings.json` d'espace de travail :

```json
{
  "mcp": {
    "servers": {
      "aptlystar-astrax": {
        "type": "http",
        "url": "https://www.aptlystar.ai/api/mcp/astrax",
        "headers": {
          "X-API-Key": "YOUR_ASTRAX_API_KEY"
        }
      }
    }
  }
}
```

Remplacez `YOUR_ASTRAX_API_KEY` par votre clé.
