Rootly

Manage incidents, alerts, and on-call with Rootly

Instructions d'utilisation

Integrate Rootly incident management into workflows. Create and manage incidents, alerts, services, severities, and retrospectives.

Outils

rootly_create_incident

Create a new incident in Rootly with optional severity, services, and teams.

Entrée

ParamètreTypeObligatoireDescription
apiKeystringOuiRootly API key
titlestringNonThe title of the incident (auto-generated if not provided)
summarystringNonA summary of the incident
severityIdstringNonSeverity ID to attach to the incident
statusstringNonIncident status (in_triage, started, detected, acknowledged, mitigated, resolved, closed, cancelled, scheduled, in_progress, completed)
kindstringNonIncident kind (normal, normal_sub, test, test_sub, example, example_sub, backfilled, scheduled, scheduled_sub)
serviceIdsstringNonComma-separated service IDs to attach
environmentIdsstringNonComma-separated environment IDs to attach
groupIdsstringNonComma-separated team/group IDs to attach
incidentTypeIdsstringNonComma-separated incident type IDs to attach
functionalityIdsstringNonComma-separated functionality IDs to attach
labelsstringNonLabels as JSON object, e.g. {"platform":"osx","version":"1.29"}
privatebooleanNonCreate as a private incident (cannot be undone)

Sortie

ParamètreTypeDescription
incidentobjectThe created incident
↳ idstringUnique incident ID
↳ sequentialIdnumberSequential incident number
↳ titlestringIncident title
↳ slugstringIncident slug
↳ kindstringIncident kind
↳ summarystringIncident summary
↳ statusstringIncident status
↳ privatebooleanWhether the incident is private
↳ urlstringURL to the incident
↳ shortUrlstringShort URL to the incident
↳ severityNamestringSeverity name
↳ severityIdstringSeverity ID
↳ createdAtstringCreation date
↳ updatedAtstringLast update date
↳ startedAtstringStart date
↳ mitigatedAtstringMitigation date
↳ resolvedAtstringResolution date
↳ closedAtstringClosed date
