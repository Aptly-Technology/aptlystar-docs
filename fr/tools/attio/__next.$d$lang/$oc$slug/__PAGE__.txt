Instructions d'utilisation [#instructions-dutilisation]

Connect to Attio to manage CRM records (people, companies, custom objects), notes, tasks, lists, list entries, comments, workspace members, and webhooks.

Outils [#outils]

attio_list_records [#attio_list_records]

Query and list records for a given object type (e.g. people, companies)

Entrée [#entrée]

| Paramètre    | Type   | Obligatoire | Description                                                                 |
| ------------ | ------ | ----------- | --------------------------------------------------------------------------- |
| `objectType` | string | Oui         | The object type slug (e.g. people, companies)                               |
| `filter`     | string | Non         | JSON filter object for querying records                                     |
| `sorts`      | string | Non         | JSON array of sort objects, e.g. \[\{"direction":"asc","attribute":"name"}] |
| `limit`      | number | Non         | Maximum number of records to return (default 500)                           |
| `offset`     | number | Non         | Number of records to skip for pagination                                    |

Sortie [#sortie]

| Paramètre        | Type   | Description                     |
| ---------------- | ------ | ------------------------------- |
| `records`        | array  | Array of Attio records          |
| ↳ `id`           | object | The record identifier           |
| ↳ `workspace_id` | string | The workspace ID                |
| ↳ `object_id`    | string | The object ID                   |
