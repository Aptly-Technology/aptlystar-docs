Instructions d'utilisation [#instructions-dutilisation]

Integrate with Agiloft contract lifecycle management to create, read, update, delete, and search records. Supports file attachments, SQL-based selection, saved searches, and record locking across any table in your knowledge base.

Outils [#outils]

agiloft_attach_file [#agiloft_attach_file]

Attach a file to a field in an Agiloft record.

Entrée [#entrée]

| Paramètre       | Type   | Obligatoire | Description                                                                                     |
| --------------- | ------ | ----------- | ----------------------------------------------------------------------------------------------- |
| `instanceUrl`   | string | Oui         | Agiloft instance URL (e.g., [https://mycompany.agiloft.com\\](https://mycompany.agiloft.com\\)) |
| `knowledgeBase` | string | Oui         | Knowledge base name                                                                             |
| `login`         | string | Oui         | Agiloft username                                                                                |
| `password`      | string | Oui         | Agiloft password                                                                                |
| `table`         | string | Oui         | Table name (e.g., "contracts")                                                                  |
| `recordId`      | string | Oui         | ID of the record to attach the file to                                                          |
| `fieldName`     | string | Oui         | Name of the attachment field                                                                    |
| `file`          | file   | Non         | File to attach                                                                                  |
| `fileName`      | string | Non         | Name to assign to the file (defaults to original file name)                                     |

Sortie [#sortie]

| Paramètre          | Type   | Description                                                     |
| ------------------ | ------ | --------------------------------------------------------------- |
| `recordId`         | string | ID of the record the file was attached to                       |
| `fieldName`        | string | Name of the field the file was attached to                      |
| `fileName`         | string | Name of the attached file                                       |
| `totalAttachments` | number | Total number of files attached in the field after the operation |
