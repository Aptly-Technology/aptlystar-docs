iam_list_users [#iam_list_users]

List IAM users in your AWS account

Entrée [#entrée]

| Paramètre         | Type   | Obligatoire | Description                                             |
| ----------------- | ------ | ----------- | ------------------------------------------------------- |
| `region`          | string | Oui         | AWS region (e.g., us-east-1)                            |
| `accessKeyId`     | string | Oui         | AWS access key ID                                       |
| `secretAccessKey` | string | Oui         | AWS secret access key                                   |
| `pathPrefix`      | string | Non         | Path prefix to filter users (e.g., /division\_abc/)     |
| `maxItems`        | number | Non         | Maximum number of users to return (1-1000, default 100) |
| `marker`          | string | Non         | Pagination marker from a previous request               |

Sortie [#sortie]

| Paramètre     | Type    | Description                                                   |
| ------------- | ------- | ------------------------------------------------------------- |
| `users`       | json    | List of IAM users with userName, userId, arn, path, and dates |

| `marker`      | string  | Pagination marker for the next page of results                |
| `count`       | number  | Number of users returned                                      |
