Instructions d'utilisation [#instructions-dutilisation]

Integrate Amplitude into your workflow to track events, identify users and groups, search for users, query analytics, and retrieve revenue data.

Outils [#outils]

amplitude_send_event [#amplitude_send_event]

Track an event in Amplitude using the HTTP V2 API.

Entrée [#entrée]

| Paramètre         | Type   | Obligatoire | Description                                                                            |
| ----------------- | ------ | ----------- | -------------------------------------------------------------------------------------- |
| `apiKey`          | string | Oui         | Amplitude API Key                                                                      |
| `userId`          | string | Non         | User ID (required if no device\_id)                                                    |
| `deviceId`        | string | Non         | Device ID (required if no user\_id)                                                    |
| `eventType`       | string | Oui         | Name of the event (e.g., "page\_view", "purchase")                                     |
| `eventProperties` | string | Non         | JSON object of custom event properties                                                 |
| `userProperties`  | string | Non         | JSON object of user properties to set (supports $set, $setOnce, $add, $append, $unset) |
| `time`            | string | Non         | Event timestamp in milliseconds since epoch                                            |
| `sessionId`       | string | Non         | Session start time in milliseconds since epoch                                         |
| `insertId`        | string | Non         | Unique ID for deduplication (within 7-day window)                                      |
| `appVersion`      | string | Non         | Application version string                                                             |
| `platform`        | string | Non         | Platform (e.g., "Web", "iOS", "Android")                                               |
| `country`         | string | Non         | Two-letter country code                                                                |
| `language`        | string | Non         | Language code (e.g., "en")                                                             |
| `ip`              | string | Non         | IP address for geo-location                                                            |
| `price`           | string | Non         | Price of the item purchased                                                            |
| `quantity`        | string | Non         | Quantity of items purchased                                                            |
| `revenue`         | string | Non         | Revenue amount                                                                         |
| `productId`       | string | Non         | Product identifier                                                                     |
| `revenueType`     | string | Non         | Revenue type (e.g., "purchase", "refund")                                              |

Sortie [#sortie]

| Paramètre          | Type   | Description                     |
| ------------------ | ------ | ------------------------------- |
| `code`             | number | Response code (200 for success) |
| `eventsIngested`   | number | Number of events ingested       |
| `payloadSizeBytes` | number | Size of the payload in bytes    |
| `serverUploadTime` | number | Server upload timestamp         |
