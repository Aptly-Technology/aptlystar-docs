Dagster

Orchestrate data pipelines and manage job runs with Dagster

Instructions d'utilisation

Connect to a Dagster instance to launch job runs, monitor run status, list available jobs across repositories, terminate or delete runs, reexecute failed runs, fetch run logs, and manage schedules and sensors. API token only required for Dagster+.

Outils

dagster_launch_run

Launch a job run on a Dagster instance.

Entrée

ParamètreTypeObligatoireDescription
hoststringOuiDagster host URL (e.g., https://myorg.dagster.cloud/prod or http://localhost:3000\)
apiKeystringNonDagster+ API token (leave blank for Dagster OSS or when not using Dagster+)
repositoryLocationNamestringOuiRepository location (code location) name
repositoryNamestringOuiRepository name within the code location
jobNamestringOuiName of the job to launch
runConfigJsonstringNonRun configuration as a JSON object (optional)
tagsstringNonTags as a JSON array of {key, value} objects (optional)

Sortie

ParamètreTypeDescription
runIdstringThe globally unique ID of the launched run

Get the status and details of a Dagster run by its ID.

Entrée

ParamètreTypeObligatoireDescription
hoststringOuiDagster host URL (e.g., https://myorg.dagster.cloud/prod or http://localhost:3000\)
apiKeystringNonDagster+ API token (leave blank for Dagster OSS or when not using Dagster+)
runIdstringOuiThe ID of the run to retrieve

Sortie

ParamètreTypeDescription
runIdstringRun ID
jobNamestringName of the job this run belongs to
statusstringRun status (QUEUED, NOT_STARTED, STARTING, MANAGED, STARTED, SUCCESS, FAILURE, CANCELING, CANCELED)
startTimenumberRun start time as Unix timestamp
endTimenumberRun end time as Unix timestamp
runConfigYamlstringRun configuration as YAML
tagsjsonRun tags as array of {key, value} objects

dagster_get_run_logs

Fetch execution event logs for a Dagster run.

Entrée

ParamètreTypeObligatoireDescription
hoststringOuiDagster host URL (e.g., https://myorg.dagster.cloud/prod or http://localhost:3001\)
apiKeystringNonDagster+ API token (leave blank for Dagster OSS or when not using Dagster+)
runIdstringOuiThe ID of the run to fetch logs for
afterCursorstringNonCursor for paginating through log events (from a previous response)
limitnumberNonMaximum number of log events to return

Sortie

ParamètreTypeDescription
eventsjsonArray of log events (type, message, timestamp, level, stepKey, eventType)
↳ typestringGraphQL typename of the event
↳ messagestringHuman-readable log message
↳ timestampstringEvent timestamp as a Unix epoch string
↳ levelstringLog level (DEBUG, INFO, WARNING, ERROR, CRITICAL)
↳ stepKeystringStep key, if the event is step-scoped
↳ eventTypestringDagster event type enum value
cursorstringCursor for fetching the next page of log events
hasMorebooleanWhether more log events are available beyond this page

hasMorebooleanWhether more runs are likely available beyond this page

dagster_get_asset

Get an asset definition and its latest materialization by asset key.

Entrée

ParamètreTypeObligatoireDescription
hoststringOuiDagster host URL (e.g., https://myorg.dagster.cloud/prod or http://localhost:3001\)
apiKeystringNonDagster+ API token (leave blank for OSS / self-hosted)
assetKeystringOuiSlash-delimited asset key, e.g. "my_asset" or "raw/events"

Sortie

ParamètreTypeDescription
assetKeystringSlash-joined asset key
pathjsonAsset key path segments
groupNamestringAsset group the definition belongs to
descriptionstringAsset description
jobNamesjsonNames of jobs that can materialize this asset
computeKindstringCompute kind tag (e.g., python, dbt, spark)
isPartitionedbooleanWhether the asset is partitioned
latestMaterializationjsonMost recent materialization (runId, timestamp, partition, stepKey)
↳ runIdstringRun that produced the materialization
↳ timestampstringMaterialization timestamp (epoch ms string)
↳ partitionstringPartition key, if partitioned
↳ stepKeystringStep key that emitted it

apiKeystringNonDagster+ API token (leave blank for OSS / self-hosted)
repositoryLocationNamestringOuiRepository location (code location) name
repositoryNamestringOuiRepository name within the code location
jobNamestringOuiAsset job that contains the assets, e.g. "__ASSET_JOB" or a named asset job
assetSelectionstringOuiComma- or newline-separated asset keys to materialize, each slash-delimited (e.g. "raw/events, summary")
tagsstringNonTags as a JSON array of {key, value} objects (optional)
