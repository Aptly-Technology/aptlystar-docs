google_translate_text [#google_translate_text]

Translate text between languages using the Google Cloud Translation API. Supports auto-detection of the source language.

Entrée [#entrée]

| Paramètre   | Type   | Obligatoire | Description                                                                     |
| ----------- | ------ | ----------- | ------------------------------------------------------------------------------- |
| `apiKey`    | string | Oui         | Google Cloud API key with Cloud Translation API enabled                         |
| `text`      | string | Oui         | The text to translate                                                           |
| `target`    | string | Oui         | Target language code (e.g., "es", "fr", "de", "ja")                             |
| `source`    | string | Non         | Source language code. If omitted, the API will auto-detect the source language. |
| `format`    | string | Non         | Format of the text: "text" for plain text, "html" for HTML content              |
| `pricing`   | custom | Non         | No description                                                                  |
| `metadata`  | string | Non         | No description                                                                  |
| `rateLimit` | string | Non         | No description                                                                  |

Sortie [#sortie]

| Paramètre                | Type   | Description                                                     |
| ------------------------ | ------ | --------------------------------------------------------------- |
| `translatedText`         | string | The translated text                                             |
| `detectedSourceLanguage` | string | The detected source language code (if source was not specified) |

google_translate_detect [#google_translate_detect]

Entrée [#entrée-1]

| `pricing`   | custom | Non         | No description                                          |
| `metadata`  | string | Non         | No description                                          |
| `rateLimit` | string | Non         | No description                                          |

| ------------ | ------ | --------------------------------------------------- |
| `language`   | string | The detected language code (e.g., "en", "es", "fr") |
| `confidence` | number | Confidence score of the detection                   |
