Instructions d'utilisation [#instructions-dutilisation]

Integrates Brex into the workflow. List and update expenses, upload and match receipts, view card and cash transactions, accounts, budgets, spend limits, vendors, transfers, and team data.

Outils [#outils]

brex_list_expenses [#brex_list_expenses]

List expenses in the Brex account with optional filters for user, status, payment status, and purchase date range

Entrée [#entrée]

| Paramètre          | Type   | Obligatoire | Description                                                                                                                                                                      |
| ------------------ | ------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apiKey`           | string | Oui         | Brex user token (generated from Developer Settings in the Brex dashboard)                                                                                                        |
| `userIds`          | string | Non         | Comma-separated user IDs to filter expenses by owner                                                                                                                             |
| `statuses`         | string | Non         | Comma-separated expense statuses to filter by: DRAFT, SUBMITTED, APPROVED, OUT\_OF\_POLICY, VOID, CANCELED, SPLIT, SETTLED                                                       |
| `paymentStatuses`  | string | Non         | Comma-separated payment statuses to filter by: NOT\_STARTED, PROCESSING, CANCELED, DECLINED, CLEARED, REFUNDING, REFUNDED, CASH\_ADVANCE, CREDITED, AWAITING\_PAYMENT, SCHEDULED |
| `purchasedAtStart` | string | Non         | Only include expenses purchased at or after this ISO 8601 timestamp                                                                                                              |
| `purchasedAtEnd`   | string | Non         | Only include expenses purchased at or before this ISO 8601 timestamp                                                                                                             |
| `cursor`           | string | Non         | Pagination cursor from a previous response                                                                                                                                       |
| `limit`            | string | Non         | Number of expenses to return (max 100)                                                                                                                                           |

Sortie [#sortie]

| Paramètre            | Type   | Description                                                                                                                                        |
| -------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`              | array  | Expenses matching the filters                                                                                                                      |
| ↳ `id`               | string | Unique expense ID                                                                                                                                  |
| ↳ `memo`             | string | Memo on the expense                                                                                                                                |
