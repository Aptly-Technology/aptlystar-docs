Instructions d'utilisation [#instructions-dutilisation]

Integrate PagerDuty into your workflow to list, create, and update incidents, add notes, list services, and check on-call schedules.

Outils [#outils]

pagerduty_list_incidents [#pagerduty_list_incidents]

List incidents from PagerDuty with optional filters.

Entrée [#entrée]

| Paramètre    | Type   | Obligatoire | Description                                                            |
| ------------ | ------ | ----------- | ---------------------------------------------------------------------- |
| `apiKey`     | string | Oui         | PagerDuty REST API Key                                                 |
| `statuses`   | string | Non         | Comma-separated statuses to filter (triggered, acknowledged, resolved) |
| `serviceIds` | string | Non         | Comma-separated service IDs to filter                                  |
| `since`      | string | Non         | Start date filter (ISO 8601 format)                                    |
| `until`      | string | Non         | End date filter (ISO 8601 format)                                      |
| `sortBy`     | string | Non         | Sort field (e.g., created\_at:desc)                                    |
| `limit`      | string | Non         | Maximum number of results (max 100)                                    |

Sortie [#sortie]

| Paramètre                | Type    | Description                        |
| ------------------------ | ------- | ---------------------------------- |
| `incidents`              | array   | Array of incidents                 |
| ↳ `id`                   | string  | Incident ID                        |
| ↳ `incidentNumber`       | number  | Incident number                    |
| ↳ `title`                | string  | Incident title                     |
| ↳ `status`               | string  | Incident status                    |
| ↳ `urgency`              | string  | Incident urgency                   |
| ↳ `createdAt`            | string  | Creation timestamp                 |
| ↳ `updatedAt`            | string  | Last updated timestamp             |
| ↳ `serviceName`          | string  | Service name                       |
| ↳ `serviceId`            | string  | Service ID                         |
| ↳ `assigneeName`         | string  | Assignee name                      |
| ↳ `assigneeId`           | string  | Assignee ID                        |
| ↳ `escalationPolicyName` | string  | Escalation policy name             |
| ↳ `htmlUrl`              | string  | PagerDuty web URL                  |
| `total`                  | number  | Total number of matching incidents |
| `more`                   | boolean | Whether more results are available |

pagerduty_create_incident [#pagerduty_create_incident]

Create a new incident in PagerDuty.

Entrée [#entrée-1]

| Paramètre            | Type   | Obligatoire | Description                             |
| -------------------- | ------ | ----------- | --------------------------------------- |
| `apiKey`             | string | Oui         | PagerDuty REST API Key                  |
| `fromEmail`          | string | Oui         | Email address of a valid PagerDuty user |
| `title`              | string | Oui         | Incident title/summary                  |
| `serviceId`          | string | Oui         | ID of the PagerDuty service             |
| `urgency`            | string | Non         | Urgency level (high or low)             |
| `body`               | string | Non         | Detailed description of the incident    |
| `escalationPolicyId` | string | Non         | Escalation policy ID to assign          |
| `assigneeId`         | string | Non         | User ID to assign the incident to       |

Sortie [#sortie-1]

| Paramètre        | Type   | Description         |
| ---------------- | ------ | ------------------- |
| `id`             | string | Created incident ID |
| `incidentNumber` | number | Incident number     |
| `title`          | string | Incident title      |
| `status`         | string | Incident status     |
| `urgency`        | string | Incident urgency    |
| `createdAt`      | string | Creation timestamp  |
| `serviceName`    | string | Service name        |
| `serviceId`      | string | Service ID          |
| `htmlUrl`        | string | PagerDuty web URL   |

Update an incident in PagerDuty (acknowledge, resolve, change urgency, etc.).

Entrée [#entrée-2]

| `fromEmail`       | string | Oui         | Email address of a valid PagerDuty user |
| `incidentId`      | string | Oui         | ID of the incident to update            |
| `status`          | string | Non         | New status (acknowledged or resolved)   |
| `title`           | string | Non         | New incident title                      |
| `urgency`         | string | Non         | New urgency (high or low)               |
| `escalationLevel` | string | Non         | Escalation level to escalate to         |

Sortie [#sortie-2]

| ---------------- | ------ | ---------------------- |
| `id`             | string | Incident ID            |
| `incidentNumber` | number | Incident number        |
| `title`          | string | Incident title         |
| `status`         | string | Updated status         |
| `urgency`        | string | Updated urgency        |
| `updatedAt`      | string | Last updated timestamp |
| `htmlUrl`        | string | PagerDuty web URL      |
