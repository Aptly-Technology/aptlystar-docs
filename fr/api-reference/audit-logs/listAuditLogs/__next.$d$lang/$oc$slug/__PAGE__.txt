`GET /api/v1/audit-logs`

## Description
Retrieve audit logs for your organization with cursor-based pagination. Requires an Enterprise subscription and organization admin or owner role.

## Parameters

- **action** (query) — `string`: Filter by action type (e.g., workflow.created, workflow.deployed, member.invited).

- **resourceType** (query) — `string`: Filter by resource type (e.g., workflow, workspace, member).

- **resourceId** (query) — `string`: Filter by a specific resource ID.

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.

- **actorId** (query) — `string`: Filter by the user who performed the action. Must be a member of your organization.

- **startDate** (query) — `string`: Only return logs after this ISO 8601 timestamp (inclusive).

- **endDate** (query) — `string`: Only return logs before this ISO 8601 timestamp (inclusive).

- **includeDeparted** (query) — `boolean`: When true, includes audit logs from users who have left the organization.

- **limit** (query) — `integer`: Maximum number of audit log entries to return per page. Must be between 1 and 100.

- **cursor** (query) — `string`: Pagination cursor returned from a previous request's nextCursor field.
