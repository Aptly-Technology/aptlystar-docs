Get Audit Log Details

Retrieve a single audit log entry by ID. Requires an Enterprise subscription and organization admin or owner role.

GET/api/v1/audit-logs/{id}

Authorization

apiKey
X-API-Key<token>

Your Aptlystar API key (personal or workspace). Generate one from the Aptlystar dashboard under Settings > API Keys.

In: header

Path Parameters

id*string

The unique audit log entry identifier.
