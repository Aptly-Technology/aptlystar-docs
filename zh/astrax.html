Astrax

Astrax 是您编辑器中的助手，可帮助您使用 Aptlystar Astrax 构建和编辑工作流，同时理解和改进它们。它可以：

  • 解释：回答有关 Aptlystar 和您当前工作流的问题
  • 指导：建议编辑和最佳实践
  • 编辑：在您批准后对模块、连接和设置进行更改

Astrax 是一个由 Aptlystar 管理的服务。对于自托管部署，请在托管应用程序中生成一个 Astrax API 密钥（aptlystar.ai → 设置 → Astrax）

  1. 前往 aptlystar.ai → 设置 → Astrax 并生成一个 Astrax API 密钥
  2. 在您的自托管环境中将 ASTRAX_API_KEY 设置为该值

上下文菜单 (@)

使用 @ 符号引用各种资源，并为 Astrax 提供有关您的工作空间的更多上下文：

@ 菜单提供以下访问：

  • 聊天：引用之前的 Astrax 对话
  • 所有工作流：引用工作空间中的任何工作流
  • 工作流模块：引用工作流中的特定模块
  • 模块：引用模块类型和模板
  • 知识：引用您上传的文档和知识库
  • 文档：引用 Aptlystar 文档
  • 模板：引用工作流模板
  • 日志：引用执行日志和结果

这些上下文信息帮助 Astrax 为您的特定用例提供更准确和相关的帮助。

模式

提问

用于解释、指导和建议的问答模式，不会对您的工作流进行更改。

代理

构建和编辑模式。Astrax 提出具体的编辑建议（添加模块、连接变量、调整设置），并在您批准后应用它们。

深度级别

快速

最快且最便宜。适用于小型编辑、简单工作流程和小调整。

自动

速度与推理的平衡。推荐作为大多数任务的默认选项。

高级

适用于更大的工作流程和复杂编辑，同时保持高性能。

巨兽

提供最大推理能力，用于深度规划、调试和复杂的架构更改。

模式选择界面

您可以通过 Astrax 界面中的模式选择器轻松切换不同的推理模式：

该界面允许您：

  • 选择推理级别：从快速、自动、高级或巨兽中选择
  • 启用 MAX 模式：切换到最大推理能力，以便在需要最全面分析时使用
  • 查看模式描述：了解每种模式的优化用途

根据任务的复杂性选择您的模式——对于简单问题使用快速模式，对于复杂的架构更改使用巨兽模式。

计费与成本计算

成本如何计算

Astrax 的使用按底层 LLM 的每个 token 计费：

  • 输入标记：按提供商的基础费率计费（按成本）
  • 输出标记：按提供商的基础输出费率的 1.5 倍 计费
组件应用费率
输入inputPrice
输出outputPrice × 1.5

显示的价格反映截至 2025 年 9 月 4 日的费率。请查阅提供商文档以获取当前价格。

模型价格以每百万标记为单位。计算公式将其除以 1,000,000 以获得实际成本。请参阅成本计算页面了解背景和示例。

将鼠标悬停在任意消息上，点击 编辑 以修改并重新发送。这有助于优化你的提示。

消息队列

如果你在 Astrax 仍在回复时发送消息，该消息会被加入队列。你可以：

  • 在可展开的队列面板中查看排队的消息
  • 立即发送排队消息（会中止当前回复）
  • 从队列中移除消息

文件附件

点击附件图标即可随消息上传文件。支持的文件类型包括：

  • 图片（显示预览缩略图）
  • PDF
  • 文本文件、 JSON 、 XML
  • 其他文档格式

文件会以可点击的缩略图形式展示，点击后将在新标签页中打开。

检查点与更改

当 Astrax 对你的工作流进行更改时，会保存检查点，方便你在需要时回退。

查看检查点

将鼠标悬停在 Astrax 消息上，点击检查点图标即可查看该消息保存的工作流状态。

撤销更改

点击任意检查点的 撤销，即可将工作流恢复到该状态。确认对话框会提示此操作无法撤销。

接受更改

当 Astrax 提出更改时，你可以：

  • 接受：应用建议的更改（Mod+Shift+Enter）
  • 拒绝：忽略更改，保留当前工作流

思考块

对于复杂请求， Astrax 可能会在可展开的思考块中展示其推理过程：

  • Astrax 思考时，思考块会自动展开
  • 点击可手动展开/收起
  • 显示思考过程的持续时间
  • 帮助你理解 Astrax 如何得出解决方案

选项选择

当 Astrax 提供多个选项时，你可以通过以下方式选择：

控制键操作
1-9通过数字选择选项
向上/向下箭头在选项间导航
Enter选择高亮选项

已选中的选项会高亮显示，未选中的选项会显示删除线。

键盘快捷键

快捷键操作
@打开上下文菜单
/打开斜杠命令
Arrow Up/Down菜单项导航
Enter选择菜单项
Esc关闭菜单
Mod+Shift+Enter接受 Astrax 更改

使用限制

Astrax 的使用按底层 LLM 的 token 计费。如果达到使用上限，Astrax 会提示你增加额度。你可以以 $50、$100 为增量，基于当前基础额度增加使用量。

计费详情请参见 成本计算页面。

Astrax MCP

你可以在常用编辑器或 AI 客户端中将 Astrax 作为 MCP 服务器使用。这样可以直接在 Cursor、Claude Code、Claude Desktop 和 VS Code 等工具中构建、测试、部署和管理 Aptlystar 工作流。

生成 Astrax API 密钥

要连接 Astrax MCP 服务器，你需要一个 Astrax API 密钥：

  1. 访问 aptlystar.ai 并登录
  2. 进入 设置 → Astrax
  3. 点击 生成 API 密钥
  4. 复制密钥 — 该密钥只显示一次

密钥类似于 sk-aptlystar-astrax-...。你将在下方配置中用到它。

Cursor

将以下内容添加到你的 .cursor/mcp.json（项目级）或全局 Cursor MCP 设置中：

将 YOUR_ASTRAX_API_KEY 替换为你上面生成的密钥。

Claude Code

运行以下命令以添加 Astrax MCP 服务器：

将 YOUR_ASTRAX_API_KEY 替换为你的密钥。

Claude Desktop

Claude Desktop 需要 mcp-remote 以连接基于 HTTP 的 MCP 服务器。请将以下内容添加到你的 Claude Desktop 配置文件（macOS 上为 ~/Library/Application Support/Claude/claude_desktop_config.json）：

将 YOUR_ASTRAX_API_KEY 替换为你的密钥。

VS Code

请将以下内容添加到你的 VS Code settings.json 或工作区 .vscode/settings.json：

将 YOUR_ASTRAX_API_KEY 替换为你的密钥。

对于自托管部署，请将 https://www.aptlystar.ai 替换为你的自托管 Aptlystar URL。
