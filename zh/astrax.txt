Astrax 是您编辑器中的助手，可帮助您使用 Aptlystar Astrax 构建和编辑工作流，同时理解和改进它们。它可以：

* **解释**：回答有关 Aptlystar 和您当前工作流的问题
* **指导**：建议编辑和最佳实践
* **编辑**：在您批准后对模块、连接和设置进行更改

<Callout type="info">
  Astrax 是一个由 Aptlystar 管理的服务。对于自托管部署，请在托管应用程序中生成一个 Astrax API 密钥（aptlystar.ai → 设置 → Astrax）

  1. 前往 [aptlystar.ai](https://aptlystar.ai) → 设置 → Astrax 并生成一个 Astrax API 密钥
  2. 在您的自托管环境中将 `ASTRAX_API_KEY` 设置为该值
</Callout>

`@` 菜单提供以下访问：

* **聊天**：引用之前的 Astrax 对话
* **所有工作流**：引用工作空间中的任何工作流
* **工作流模块**：引用工作流中的特定模块
* **模块**：引用模块类型和模板
* **知识**：引用您上传的文档和知识库
* **文档**：引用 Aptlystar 文档
* **模板**：引用工作流模板
* **日志**：引用执行日志和结果

这些上下文信息帮助 Astrax 为您的特定用例提供更准确和相关的帮助。

计费与成本计算 [#计费与成本计算]

成本如何计算 [#成本如何计算]

Astrax 的使用按底层 LLM 的每个 token 计费：

* **输入标记**：按提供商的基础费率计费（**按成本**）
* **输出标记**：按提供商的基础输出费率的 **1.5 倍** 计费

```javascript
astraxCost = (inputTokens × inputPrice + outputTokens × (outputPrice × 1.5)) / 1,000,000
```

| 组件 | 应用费率              |
| -- | ----------------- |
| 输入 | inputPrice        |
| 输出 | outputPrice × 1.5 |

<Callout type="warning">
  显示的价格反映截至 2025 年 9 月 4 日的费率。请查阅提供商文档以获取当前价格。
</Callout>

<Callout type="info">
  模型价格以每百万标记为单位。计算公式将其除以 1,000,000 以获得实际成本。请参阅<a href="/execution/costs">成本计算页面</a>了解背景和示例。
</Callout>

Astrax MCP [#astrax-mcp]

你可以在常用编辑器或 AI 客户端中将 Astrax 作为 MCP 服务器使用。这样可以直接在 Cursor、Claude Code、Claude Desktop 和 VS Code 等工具中构建、测试、部署和管理 Aptlystar 工作流。

生成 Astrax API 密钥 [#生成-astrax-api-密钥]

要连接 Astrax MCP 服务器，你需要一个 **Astrax API 密钥**：

1. 访问 [aptlystar.ai](https://aptlystar.ai) 并登录
2. 进入 **设置** → **Astrax**
3. 点击 **生成 API 密钥**
4. 复制密钥 — 该密钥只显示一次

密钥类似于 `sk-aptlystar-astrax-...`。你将在下方配置中用到它。

Cursor [#cursor]

将以下内容添加到你的 `.cursor/mcp.json`（项目级）或全局 Cursor MCP 设置中：

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "url": "https://www.aptlystar.ai/api/mcp/astrax",
      "headers": {
        "X-API-Key": "YOUR_ASTRAX_API_KEY"
      }
    }
  }
}
```

将 `YOUR_ASTRAX_API_KEY` 替换为你上面生成的密钥。

Claude Code [#claude-code]

运行以下命令以添加 Astrax MCP 服务器：

```bash
claude mcp add aptlystar-astrax \
  --transport http \
  https://www.aptlystar.ai/api/mcp/astrax \
  --header "X-API-Key: YOUR_ASTRAX_API_KEY"
```

将 `YOUR_ASTRAX_API_KEY` 替换为你的密钥。

Claude Desktop [#claude-desktop]

Claude Desktop 需要 [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) 以连接基于 HTTP 的 MCP 服务器。请将以下内容添加到你的 Claude Desktop 配置文件（macOS 上为 `~/Library/Application Support/Claude/claude_desktop_config.json`）：

```json
{
  "mcpServers": {
    "aptlystar-astrax": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.aptlystar.ai/api/mcp/astrax",
        "--header",
        "X-API-Key: YOUR_ASTRAX_API_KEY"
      ]
    }
  }
}
```

将 `YOUR_ASTRAX_API_KEY` 替换为你的密钥。

VS Code [#vs-code]

请将以下内容添加到你的 VS Code `settings.json` 或工作区 `.vscode/settings.json`：

```json
{
  "mcp": {
    "servers": {
      "aptlystar-astrax": {
        "type": "http",
        "url": "https://www.aptlystar.ai/api/mcp/astrax",
        "headers": {
          "X-API-Key": "YOUR_ASTRAX_API_KEY"
        }
      }
    }
  }
}
```

将 `YOUR_ASTRAX_API_KEY` 替换为你的密钥。
