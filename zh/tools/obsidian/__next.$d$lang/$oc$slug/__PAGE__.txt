使用说明 [#使用说明]

Read, create, update, search, and delete notes in your Obsidian vault. Manage periodic notes, execute commands, and patch content at specific locations. Requires the Obsidian Local REST API plugin.

工具 [#工具]

obsidian_append_active [#obsidian_append_active]

Append content to the currently active file in Obsidian

输入 [#输入]

| 参数        | 类型     | 必填 | 描述                                                   |
| --------- | ------ | -- | ---------------------------------------------------- |
| `apiKey`  | string | 是  | API key from Obsidian Local REST API plugin settings |
| `baseUrl` | string | 是  | Base URL for the Obsidian Local REST API             |
| `content` | string | 是  | Markdown content to append to the active file        |

输出 [#输出]

| 参数         | 类型      | 描述                                        |
| ---------- | ------- | ----------------------------------------- |
| `appended` | boolean | Whether content was successfully appended |

obsidian_append_note [#obsidian_append_note]

Append content to an existing note in your Obsidian vault

输入 [#输入-1]

| 参数         | 类型     | 必填 | 描述                                                              |
| ---------- | ------ | -- | --------------------------------------------------------------- |
| `apiKey`   | string | 是  | API key from Obsidian Local REST API plugin settings            |
| `baseUrl`  | string | 是  | Base URL for the Obsidian Local REST API                        |
| `filename` | string | 是  | Path to the note relative to vault root (e.g. "folder/note.md") |
| `content`  | string | 是  | Markdown content to append to the note                          |

输出 [#输出-1]

| 参数         | 类型      | 描述                                        |
| ---------- | ------- | ----------------------------------------- |
| `filename` | string  | Path of the note                          |
| `appended` | boolean | Whether content was successfully appended |

| ---------------------- | ------- | -- | ------------------------------------------------------------------------------- |
