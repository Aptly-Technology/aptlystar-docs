Wiza

Find, enrich, and verify B2B contact data with Wiza

使用说明

Integrates Wiza into the workflow. Search prospects, enrich companies, reveal verified emails and phone numbers for individuals, and check your account credit balance.

工具

wiza_prospect_search

Search Wiza

输入

参数类型必填描述
apiKeystring是Wiza API key
sizenumber否Number of sample profiles to return (0-30, default 0)
filtersobject否Full filters object (overrides individual filter params if provided)
first_namearray否Exact first names to match (e.g., ["John", "Jane"])
last_namearray否Exact last names to match
job_titlearray否Job titles to include/exclude (e.g., [{"v":"CEO","s":"i"},{"v":"CTO","s":"e"}])
job_title_levelarray否Seniority levels (e.g., ["cxo", "director", "manager"])
job_rolearray否Job role categories (e.g., ["sales", "engineering", "marketing"])
job_sub_rolearray否Detailed role categories (e.g., ["software", "product"])
locationarray否Person's location filters (city/state/country with include/exclude)
skillarray否Professional skills (e.g., ["python", "marketing"])
schoolarray否Educational institutions
majorarray否Field of study
linkedin_slugarray否LinkedIn profile slugs
job_companyarray否Current company filters (include/exclude)
past_companyarray否Past company filters
company_locationarray否Company HQ location filters
company_industryarray否Company industry filters (include/exclude)
company_sizearray否Company headcount brackets (e.g., ["1-10", "11-50", "51-200"])
company_typearray否Company type (e.g., ["private", "public", "educational"])

输出

参数类型描述
totalnumberTotal number of matching prospects
profilesarraySample profiles matching the filter criteria

Enrich a company by name, domain, LinkedIn ID, or LinkedIn slug with detailed firmographic data

输入

company_namestring否Company name (e.g., "Wiza")
company_domainstring否Company domain (e.g., "wiza.co")
company_linkedin_idstring否Company LinkedIn ID
company_linkedin_slugstring否Company LinkedIn slug from the URL

输出

参数类型描述
company_namestringCompany name
company_domainstringCompany domain
domainstringDomain
company_industrystringIndustry
company_sizenumberEmployee count
company_size_rangestringHeadcount range
company_foundednumberYear founded
company_revenue_rangestringRevenue range
company_fundingstringTotal funding
company_typestringCompany type

company_last_funding_roundstringLast funding round
company_last_funding_amountstringLast funding amount
company_last_funding_atstringLast funding date

company_facebookstringFacebook URL
company_linkedinstringLinkedIn URL
company_linkedin_idstringLinkedIn ID

company_localitystringCity
company_regionstringState/region
company_postal_codestringPostal code
company_countrystringCountry
creditsjsonCredits deducted for this enrichment (api_credits: { total, company_credits })

wiza_individual_reveal

Reveal a contact via LinkedIn URL, name + company/domain, or email. Starts the reveal and polls until it resolves. Uses 2 credits per valid email and 5 credits per phone, charged only on success.

输入

参数类型必填描述
apiKeystring是Wiza API key
enrichment_levelstring是Enrichment depth: none, partial, phone, or full
profile_urlstring否LinkedIn profile URL (e.g., https://linkedin.com/in/johndoe\)
full_namestring否Full name (used with company or domain)
companystring否Company name (used with full_name)
domainstring否Company domain (used with full_name)
emailstring否Email address (use alone or with other identifiers)
accept_workboolean否Whether to accept work emails (email_options)
accept_personalboolean否Whether to accept personal emails (email_options)

输出

参数类型描述

statusstringqueued | resolving | finished | failed

namestringFull name

email_typestringEmail type

emailsarrayAll emails found
mobile_phonestringMobile phone
phone_numberstringDirect/office phone
phone_statusstringfound | unfound
phonesarrayAll phones found
company_sizenumberEmployee count
company_size_rangestringHeadcount range
company_typestringCompany type
company_domainstringCompany domain
company_localitystringCity
company_regionstringState/region
company_countrystringCountry
company_streetstringStreet
company_postal_codestringPostal code
company_foundednumberYear founded
company_fundingstringFunding total
company_revenuestringRevenue
company_industrystringIndustry
company_subindustrystringSubindustry
company_linkedinstringCompany LinkedIn URL
company_locationstringFull company location
company_descriptionstringCompany description
creditsjsonCredits consumed by the reveal
