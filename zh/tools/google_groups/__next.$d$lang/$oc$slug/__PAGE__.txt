使用说明 [#使用说明]

连接到 Google Workspace，使用 Admin SDK Directory API 创建、更新和管理群组及其成员。

工具 [#工具]

google_groups_list_groups [#google_groups_list_groups]

列出 Google Workspace 域中的所有群组

输入 [#输入]

| 参数           | 类型     | 必需 | 描述                               |
| ------------ | ------ | -- | -------------------------------- |
| `customer`   | string | 否  | 客户 ID 或 "my\_customer" 表示已认证用户的域 |
| `domain`     | string | 否  | 用于筛选群组的域名                        |
| `maxResults` | number | 否  | 返回的最大结果数 (1-200)                 |
| `pageToken`  | string | 否  | 分页的令牌                            |
| `query`      | string | 否  | 用于筛选群组的搜索查询 (例如："email:admin\*") |

输出 [#输出]

| 参数              | 类型     | 描述           |
| --------------- | ------ | ------------ |
| `groups`        | json   | 群组对象的数组      |
| `nextPageToken` | string | 用于获取下一页结果的令牌 |

google_groups_get_group [#google_groups_get_group]

通过电子邮件或群组 ID 获取特定 Google 群组的详细信息

输入 [#输入-1]

| 参数         | 类型     | 必需 | 描述               |
| ---------- | ------ | -- | ---------------- |
| `groupKey` | string | 是  | 群组电子邮件地址或唯一群组 ID |

输出 [#输出-1]

| 参数      | 类型   | 描述   |
| ------- | ---- | ---- |
| `group` | json | 群组对象 |

google_groups_create_group [#google_groups_create_group]

在域中创建一个新的 Google 群组

输入 [#输入-2]

| 参数            | 类型     | 必需 | 描述                                                               |
| ------------- | ------ | -- | ---------------------------------------------------------------- |
| `email`       | string | 是  | 新组的电子邮件地址 (例如：[team@yourdomain.com](mailto:team@yourdomain.com)) |
| `name`        | string | 是  | 组的显示名称                                                           |
| `description` | string | 否  | 组的描述                                                             |

输出 [#输出-2]

| 参数      | 类型   | 描述      |
| ------- | ---- | ------- |
| `group` | json | 创建的群组对象 |
