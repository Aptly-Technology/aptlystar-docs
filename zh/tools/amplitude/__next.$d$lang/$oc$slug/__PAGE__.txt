使用说明 [#使用说明]

Integrate Amplitude into your workflow to track events, identify users and groups, search for users, query analytics, and retrieve revenue data.

工具 [#工具]

amplitude_send_event [#amplitude_send_event]

Track an event in Amplitude using the HTTP V2 API.

输入 [#输入]

| 参数                | 类型     | 必填 | 描述                                                                                     |
| ----------------- | ------ | -- | -------------------------------------------------------------------------------------- |
| `apiKey`          | string | 是  | Amplitude API Key                                                                      |
| `userId`          | string | 否  | User ID (required if no device\_id)                                                    |
| `deviceId`        | string | 否  | Device ID (required if no user\_id)                                                    |
| `eventType`       | string | 是  | Name of the event (e.g., "page\_view", "purchase")                                     |
| `eventProperties` | string | 否  | JSON object of custom event properties                                                 |
| `userProperties`  | string | 否  | JSON object of user properties to set (supports $set, $setOnce, $add, $append, $unset) |
| `time`            | string | 否  | Event timestamp in milliseconds since epoch                                            |
| `sessionId`       | string | 否  | Session start time in milliseconds since epoch                                         |
| `insertId`        | string | 否  | Unique ID for deduplication (within 7-day window)                                      |
| `appVersion`      | string | 否  | Application version string                                                             |
| `platform`        | string | 否  | Platform (e.g., "Web", "iOS", "Android")                                               |
| `country`         | string | 否  | Two-letter country code                                                                |
| `language`        | string | 否  | Language code (e.g., "en")                                                             |
| `ip`              | string | 否  | IP address for geo-location                                                            |
| `price`           | string | 否  | Price of the item purchased                                                            |
| `quantity`        | string | 否  | Quantity of items purchased                                                            |
| `revenue`         | string | 否  | Revenue amount                                                                         |
| `productId`       | string | 否  | Product identifier                                                                     |
| `revenueType`     | string | 否  | Revenue type (e.g., "purchase", "refund")                                              |

输出 [#输出]

| 参数                 | 类型     | 描述                              |
| ------------------ | ------ | ------------------------------- |
| `code`             | number | Response code (200 for success) |
| `eventsIngested`   | number | Number of events ingested       |
| `payloadSizeBytes` | number | Size of the payload in bytes    |
| `serverUploadTime` | number | Server upload timestamp         |
