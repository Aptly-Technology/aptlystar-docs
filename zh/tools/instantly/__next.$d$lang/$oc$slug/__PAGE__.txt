使用说明 [#使用说明]

Integrate Instantly API V2 into workflows. Create and list leads, manage lead interest status, delete leads in bulk, list and create campaigns, reply to emails, and manage lead lists.

工具 [#工具]

instantly_list_leads [#instantly_list_leads]

Retrieves Instantly V2 leads with search, campaign, list, and pagination filters.

输入 [#输入]

| 参数                      | 类型      | 必填 | 描述                                                                                 |
| ----------------------- | ------- | -- | ---------------------------------------------------------------------------------- |
| `search`                | string  | 否  | Search by first name, last name, or email                                          |
| `filter`                | string  | 否  | Instantly lead filter value, such as FILTER\_VAL\_CONTACTED or FILTER\_VAL\_ACTIVE |
| `campaign`              | string  | 否  | Campaign ID to filter leads                                                        |
| `list_id`               | string  | 否  | Lead list ID to filter leads                                                       |
| `in_campaign`           | boolean | 否  | Whether the lead is in a campaign                                                  |
| `in_list`               | boolean | 否  | Whether the lead is in a list                                                      |
| `ids`                   | array   | 否  | Lead IDs to include                                                                |
| `items`                 | string  | 否  | No description                                                                     |
| `excluded_ids`          | array   | 否  | Lead IDs to exclude                                                                |
| `items`                 | string  | 否  | No description                                                                     |
| `organization_user_ids` | array   | 否  | Organization user IDs to filter leads                                              |
| `items`                 | string  | 否  | No description                                                                     |
| `smart_view_id`         | string  | 否  | Smart view ID to filter leads                                                      |
| `contacts`              | array   | 否  | Lead email addresses to include                                                    |
| `items`                 | string  | 否  | No description                                                                     |
| `limit`                 | number  | 否  | Number of leads to return, from 1 to 100                                           |
| `starting_after`        | string  | 否  | Forward pagination cursor from next\_starting\_after                               |
| `distinct_contacts`     | boolean | 否  | Whether to return distinct contacts                                                |
| `is_website_visitor`    | boolean | 否  | Whether the lead is a website visitor                                              |
| `enrichment_status`     | number  | 否  | Enrichment status filter                                                           |
| `esg_code`              | string  | 否  | Email security gateway code filter                                                 |

输出 [#输出]

| `lead_list`           | json   | Lead list details (id, organization\_id, has\_enrichment\_task, owned\_by, name, timestamp\_created)      |

| `next_starting_after` | string | Cursor for the next page                                                                                  |
