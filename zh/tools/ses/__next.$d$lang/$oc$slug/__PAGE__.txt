使用说明 [#使用说明]

Integrate AWS SES v2 into the workflow. Send simple, templated, and bulk emails. Manage email templates and retrieve account sending quota and verified identity information.

工具 [#工具]

ses_send_email [#ses_send_email]

Send an email via AWS SES using simple or HTML content

输入 [#输入]

| 参数                     | 类型     | 必填 | 描述                                                |
| ---------------------- | ------ | -- | ------------------------------------------------- |
| `region`               | string | 是  | AWS region (e.g., us-east-1)                      |
| `accessKeyId`          | string | 是  | AWS access key ID                                 |
| `secretAccessKey`      | string | 是  | AWS secret access key                             |
| `fromAddress`          | string | 是  | Verified sender email address                     |
| `toAddresses`          | string | 是  | Comma-separated list of recipient email addresses |
| `subject`              | string | 是  | Email subject line                                |
| `bodyText`             | string | 否  | Plain text email body                             |
| `bodyHtml`             | string | 否  | HTML email body                                   |
| `ccAddresses`          | string | 否  | Comma-separated list of CC email addresses        |
| `bccAddresses`         | string | 否  | Comma-separated list of BCC email addresses       |
| `replyToAddresses`     | string | 否  | Comma-separated list of reply-to email addresses  |
| `configurationSetName` | string | 否  | SES configuration set name for tracking           |

输出 [#输出]

| 参数          | 类型     | 描述                                |
| ----------- | ------ | --------------------------------- |
| `messageId` | string | SES message ID for the sent email |

Send an email using an SES email template with dynamic template data

输入 [#输入-1]

| 参数                     | 类型     | 必填 | 描述                                                                |

| `secretAccessKey`      | string | 是  | AWS secret access key                                             |
| `fromAddress`          | string | 是  | Verified sender email address                                     |
| `toAddresses`          | string | 是  | Comma-separated list of recipient email addresses                 |
| `templateName`         | string | 是  | Name of the SES email template to use                             |
| `templateData`         | string | 是  | JSON string of key-value pairs for template variable substitution |
| `ccAddresses`          | string | 否  | Comma-separated list of CC email addresses                        |
| `bccAddresses`         | string | 否  | Comma-separated list of BCC email addresses                       |
| `configurationSetName` | string | 否  | SES configuration set name for tracking                           |

输出 [#输出-1]

| 参数          | 类型     | 描述                                |
| ----------- | ------ | --------------------------------- |
| `messageId` | string | SES message ID for the sent email |

ses_send_bulk_email [#ses_send_bulk_email]

Send emails to multiple recipients using an SES template with per-recipient data

输入 [#输入-2]

| 参数                     | 类型     | 必填 | 描述                                                                                                                                                     |

| `templateName`         | string | 是  | Name of the SES email template to use                                                                                                                  |
