使用说明 [#使用说明]

Generate SVG images from text prompts or vectorize raster images into SVGs using QuiverAI. Supports reference images, style instructions, and multiple output generation.

工具 [#工具]

quiver_text_to_svg [#quiver_text_to_svg]

Generate SVG images from text prompts using QuiverAI

输入 [#输入]

| 参数                  | 类型     | 必填 | 描述                                                          |
| ------------------- | ------ | -- | ----------------------------------------------------------- |
| `apiKey`            | string | 是  | QuiverAI API key                                            |
| `prompt`            | string | 是  | A text description of the desired SVG                       |
| `model`             | string | 是  | The model to use for SVG generation (e.g., "arrow-preview") |
| `instructions`      | string | 否  | Style or formatting guidance for the SVG output             |
| `references`        | file   | 否  | Reference images to guide SVG generation (up to 4)          |
| `n`                 | number | 否  | Number of SVGs to generate (1-16, default 1)                |
| `temperature`       | number | 否  | Sampling temperature (0-2, default 1)                       |
| `top_p`             | number | 否  | Nucleus sampling probability (0-1, default 1)               |
| `max_output_tokens` | number | 否  | Maximum output tokens (1-131072)                            |
| `presence_penalty`  | number | 否  | Token penalty for prior output (-2 to 2, default 0)         |

输出 [#输出]

| 参数               | 类型      | 描述                                         |
| ---------------- | ------- | ------------------------------------------ |
| `success`        | boolean | Whether the SVG generation succeeded       |
| `output`         | object  | Generated SVG output                       |
| ↳ `file`         | file    | First generated SVG file                   |
| ↳ `files`        | json    | All generated SVG files (when n > 1)       |
| ↳ `svgContent`   | string  | Raw SVG markup content of the first result |
| ↳ `id`           | string  | Generation request ID                      |
| ↳ `usage`        | json    | Token usage statistics                     |
| ↳ `totalTokens`  | number  | Total tokens used                          |
| ↳ `inputTokens`  | number  | Input tokens used                          |
| ↳ `outputTokens` | number  | Output tokens used                         |

quiver_image_to_svg [#quiver_image_to_svg]

Convert raster images into vector SVG format using QuiverAI

输入 [#输入-1]

| 参数                  | 类型      | 必填 | 描述                                                         |
| ------------------- | ------- | -- | ---------------------------------------------------------- |
| `apiKey`            | string  | 是  | QuiverAI API key                                           |
| `model`             | string  | 是  | The model to use for vectorization (e.g., "arrow-preview") |
| `image`             | file    | 是  | The raster image to vectorize into SVG                     |
| `temperature`       | number  | 否  | Sampling temperature (0-2, default 1)                      |
| `top_p`             | number  | 否  | Nucleus sampling probability (0-1, default 1)              |
| `max_output_tokens` | number  | 否  | Maximum output tokens (1-131072)                           |
| `presence_penalty`  | number  | 否  | Token penalty for prior output (-2 to 2, default 0)        |
| `auto_crop`         | boolean | 否  | Automatically crop the image before vectorizing            |
| `target_size`       | number  | 否  | Square resize target in pixels (128-4096)                  |

输出 [#输出-1]

| 参数               | 类型      | 描述                                  |
| ---------------- | ------- | ----------------------------------- |
| `success`        | boolean | Whether the vectorization succeeded |
| `output`         | object  | Vectorized SVG output               |
| ↳ `file`         | file    | Generated SVG file                  |
| ↳ `svgContent`   | string  | Raw SVG markup content              |
| ↳ `id`           | string  | Vectorization request ID            |
| ↳ `usage`        | json    | Token usage statistics              |
| ↳ `totalTokens`  | number  | Total tokens used                   |
| ↳ `inputTokens`  | number  | Input tokens used                   |
| ↳ `outputTokens` | number  | Output tokens used                  |

quiver_list_models [#quiver_list_models]

List all available QuiverAI models

输入 [#输入-2]

| 参数       | 类型     | 必填 | 描述               |
| -------- | ------ | -- | ---------------- |
| `apiKey` | string | 是  | QuiverAI API key |

输出 [#输出-2]

| 参数                              | 类型      | 描述                                                                                                        |
| ------------------------------- | ------- | --------------------------------------------------------------------------------------------------------- |
| `success`                       | boolean | Whether the request succeeded                                                                             |
| `output`                        | object  | Available models                                                                                          |
| ↳ `models`                      | json    | List of available QuiverAI models                                                                         |
| ↳ `id`                          | string  | Model identifier                                                                                          |
| ↳ `name`                        | string  | Human-readable model name                                                                                 |
| ↳ `description`                 | string  | Model capabilities summary                                                                                |
| ↳ `created`                     | number  | Unix timestamp of creation                                                                                |
| ↳ `ownedBy`                     | string  | Organization that owns the model                                                                          |
| ↳ `inputModalities`             | json    | Supported input types (text, image, svg)                                                                  |
| ↳ `outputModalities`            | json    | Supported output types (text, image, svg)                                                                 |
| ↳ `contextLength`               | number  | Maximum context window                                                                                    |
| ↳ `maxOutputLength`             | number  | Maximum generation length                                                                                 |
| ↳ `supportedOperations`         | json    | Available operations (svg\_generate, svg\_edit, svg\_animate, svg\_vectorize, chat\_completions)          |
| ↳ `supportedSamplingParameters` | json    | Supported sampling parameters (temperature, top\_p, top\_k, repetition\_penalty, presence\_penalty, stop) |
