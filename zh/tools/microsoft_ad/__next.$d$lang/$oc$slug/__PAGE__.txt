使用说明 [#使用说明]

Integrate Azure Active Directory into your workflows. List, create, update, and delete users and groups. Manage group memberships programmatically.

工具 [#工具]

microsoft_ad_list_users [#microsoft_ad_list_users]

List users in Azure AD (Microsoft Entra ID)

输入 [#输入]

| 参数       | 类型     | 必填 | 描述                                                       |
| -------- | ------ | -- | -------------------------------------------------------- |
| `top`    | number | 否  | Maximum number of users to return (default 100, max 999) |
| `filter` | string | 否  | OData filter expression (e.g., "department eq 'Sales'")  |
| `search` | string | 否  | Search string to filter users by displayName or mail     |

输出 [#输出]

| 参数          | 类型     | 描述                       |
| ----------- | ------ | ------------------------ |
| `users`     | array  | List of users            |
| `userCount` | number | Number of users returned |

microsoft_ad_get_user [#microsoft_ad_get_user]

Get a user by ID or user principal name from Azure AD

输入 [#输入-1]

| 参数       | 类型     | 必填 | 描述                                                                                   |
| -------- | ------ | -- | ------------------------------------------------------------------------------------ |
| `userId` | string | 是  | User ID or user principal name (e.g., "[user@example.com](mailto:user@example.com)") |

| 参数                    | 类型      | 描述                             |
| --------------------- | ------- | ------------------------------ |
| `user`                | object  | User details                   |
