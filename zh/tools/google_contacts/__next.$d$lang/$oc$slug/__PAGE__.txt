使用说明 [#使用说明]

Integrate Google Contacts into the workflow. Can create, read, update, delete, list, and search contacts.

工具 [#工具]

google_contacts_create [#google_contacts_create]

Create a new contact in Google Contacts

输入 [#输入]

| 参数             | 类型     | 必填 | 描述                                       |
| -------------- | ------ | -- | ---------------------------------------- |
| `givenName`    | string | 是  | First name of the contact                |
| `familyName`   | string | 否  | Last name of the contact                 |
| `email`        | string | 否  | Email address of the contact             |
| `emailType`    | string | 否  | Email type: home, work, or other         |
| `phone`        | string | 否  | Phone number of the contact              |
| `phoneType`    | string | 否  | Phone type: mobile, home, work, or other |
| `organization` | string | 否  | Organization/company name                |
| `jobTitle`     | string | 否  | Job title at the organization            |
| `notes`        | string | 否  | Notes or biography for the contact       |

输出 [#输出]

| 参数         | 类型     | 描述                                                           |
| ---------- | ------ | ------------------------------------------------------------ |
| `content`  | string | Contact creation confirmation message                        |
| `metadata` | json   | Created contact metadata including resource name and details |

google_contacts_get [#google_contacts_get]

Get a specific contact from Google Contacts

输入 [#输入-1]

| 参数             | 类型     | 必填 | 描述                                                      |
| -------------- | ------ | -- | ------------------------------------------------------- |
| `resourceName` | string | 是  | Resource name of the contact (e.g., people/c1234567890) |

输出 [#输出-1]

| 参数         | 类型     | 描述                                                             |
| ---------- | ------ | -------------------------------------------------------------- |
| `content`  | string | Contact retrieval confirmation message                         |
| `metadata` | json   | Contact details including name, email, phone, and organization |

google_contacts_list [#google_contacts_list]

List contacts from Google Contacts

输入 [#输入-2]

| 参数          | 类型     | 必填 | 描述                                                     |
| ----------- | ------ | -- | ------------------------------------------------------ |
| `pageSize`  | number | 否  | Number of contacts to return (1-1000, default 100)     |
| `pageToken` | string | 否  | Page token from a previous list request for pagination |
| `sortOrder` | string | 否  | Sort order for contacts                                |

输出 [#输出-2]

| 参数         | 类型     | 描述                                      |
| ---------- | ------ | --------------------------------------- |
| `content`  | string | Summary of found contacts count         |
| `metadata` | json   | List of contacts with pagination tokens |

google_contacts_search [#google_contacts_search]

Search contacts in Google Contacts by name, email, phone, or organization

输入 [#输入-3]

| 参数         | 类型     | 必填 | 描述                                                                             |
| ---------- | ------ | -- | ------------------------------------------------------------------------------ |
| `query`    | string | 是  | Search query to match against contact names, emails, phones, and organizations |
| `pageSize` | number | 否  | Number of results to return (default 10, max 30)                               |

输出 [#输出-3]

| 参数         | 类型     | 描述                                    |
| ---------- | ------ | ------------------------------------- |
| `content`  | string | Summary of search results count       |
| `metadata` | json   | Search results with matching contacts |

google_contacts_update [#google_contacts_update]

Update an existing contact in Google Contacts

输入 [#输入-4]

| 参数             | 类型     | 必填 | 描述                                                                  |
| -------------- | ------ | -- | ------------------------------------------------------------------- |
| `resourceName` | string | 是  | Resource name of the contact (e.g., people/c1234567890)             |
| `etag`         | string | 是  | ETag from a previous get request (required for concurrency control) |
| `givenName`    | string | 否  | Updated first name                                                  |
| `familyName`   | string | 否  | Updated last name                                                   |
| `email`        | string | 否  | Updated email address                                               |
| `emailType`    | string | 否  | Email type: home, work, or other                                    |
| `phone`        | string | 否  | Updated phone number                                                |
| `phoneType`    | string | 否  | Phone type: mobile, home, work, or other                            |
| `organization` | string | 否  | Updated organization/company name                                   |
| `jobTitle`     | string | 否  | Updated job title                                                   |
| `notes`        | string | 否  | Updated notes or biography                                          |

输出 [#输出-4]

| 参数         | 类型     | 描述                                  |
| ---------- | ------ | ----------------------------------- |
| `content`  | string | Contact update confirmation message |
| `metadata` | json   | Updated contact metadata            |

google_contacts_delete [#google_contacts_delete]

Delete a contact from Google Contacts

输入 [#输入-5]

| 参数             | 类型     | 必填 | 描述                                                                |
| -------------- | ------ | -- | ----------------------------------------------------------------- |
| `resourceName` | string | 是  | Resource name of the contact to delete (e.g., people/c1234567890) |

输出 [#输出-5]

| 参数         | 类型     | 描述                                       |
| ---------- | ------ | ---------------------------------------- |
| `content`  | string | Contact deletion confirmation message    |
| `metadata` | json   | Deletion details including resource name |
