使用说明 [#使用说明]

Give your workflow a phone. Provision SMS- and voice-enabled numbers, send messages and tapback reactions, place outbound voice calls, manage conversations and contacts, and track usage — all through a single AgentPhone API key.

工具 [#工具]

agentphone_create_call [#agentphone_create_call]

Initiate an outbound voice call from an AgentPhone agent

输入 [#输入]

| 参数                | 类型     | 必填 | 描述                                                                                                                    |
| ----------------- | ------ | -- | --------------------------------------------------------------------------------------------------------------------- |
| `apiKey`          | string | 是  | AgentPhone API key                                                                                                    |
| `agentId`         | string | 是  | Agent that will handle the call                                                                                       |
| `toNumber`        | string | 是  | Phone number to call in E.164 format (e.g. +14155551234)                                                              |
| `fromNumberId`    | string | 否  | Phone number ID to use as caller ID. Must belong to the agent. If omitted, the agent's first assigned number is used. |
| `initialGreeting` | string | 否  | Optional greeting spoken when the recipient answers                                                                   |
| `voice`           | string | 否  | Voice ID override for this call (defaults to the agent's configured voice)                                            |
| `systemPrompt`    | string | 否  | When provided, uses a built-in LLM for the conversation instead of forwarding to your webhook                         |

输出 [#输出]

| 参数              | 类型     | 描述                                       |
| --------------- | ------ | ---------------------------------------- |
| `id`            | string | Unique call identifier                   |
| `agentId`       | string | Agent handling the call                  |
| `status`        | string | Initial call status                      |
| `toNumber`      | string | Destination phone number                 |
| `fromNumber`    | string | Caller ID used for the call              |
| `phoneNumberId` | string | ID of the phone number used as caller ID |
| `direction`     | string | Call direction (outbound)                |
| `startedAt`     | string | ISO 8601 timestamp                       |

Provision a new SMS- and voice-enabled phone number
