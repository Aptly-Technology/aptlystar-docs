使用说明 [#使用说明]

Integrate New Relic into workflows. Run NRQL queries, search monitored entities, fetch entity details, and record deployment change events.

工具 [#工具]

new_relic_nrql_query [#new_relic_nrql_query]

Run a NRQL query against a New Relic account using NerdGraph.

输入 [#输入]

| 参数          | 类型     | 必填 | 描述                                     |
| ----------- | ------ | -- | -------------------------------------- |
| `apiKey`    | string | 是  | New Relic user API key for NerdGraph   |
| `region`    | string | 否  | New Relic data center region: us or eu |
| `accountId` | number | 是  | New Relic account ID to query          |
| `nrql`      | string | 是  | NRQL query to execute                  |
| `timeout`   | number | 否  | Optional query timeout in seconds      |

输出 [#输出]

| 参数            | 类型     | 描述                                                           |
| ------------- | ------ | ------------------------------------------------------------ |
| `results`     | array  | NRQL result rows. Row fields depend on the query projection. |
| `resultCount` | number | Number of NRQL result rows returned                          |

new_relic_search_entities [#new_relic_search_entities]

Search New Relic entities by name, GUID, domain type, tags, or reporting state.

输入 [#输入-1]

| 参数       | 类型     | 必填 | 描述                                                                                  |
| -------- | ------ | -- | ----------------------------------------------------------------------------------- |
| `apiKey` | string | 是  | New Relic user API key for NerdGraph                                                |
| `region` | string | 否  | New Relic data center region: us or eu                                              |
| `query`  | string | 是  | Entity search query, for example: name like "api" or domainType = "APM-APPLICATION" |
| `cursor` | string | 否  | Pagination cursor from a previous entity search                                     |

输出 [#输出-1]

| 参数             | 类型     | 描述                                          |
| -------------- | ------ | ------------------------------------------- |
| `count`        | number | Total number of entities matching the query |
| `query`        | string | Entity search query New Relic executed      |
| `entities`     | array  | Matching New Relic entities                 |
| ↳ `guid`       | string | Entity GUID                                 |
| ↳ `name`       | string | Entity name                                 |
| ↳ `entityType` | string | Entity type                                 |
| `nextCursor`   | string | Cursor for the next page of results         |

new_relic_get_entity [#new_relic_get_entity]

Fetch a New Relic entity by GUID.

输入 [#输入-2]

| 参数       | 类型     | 必填 | 描述                                     |
| -------- | ------ | -- | -------------------------------------- |
| `apiKey` | string | 是  | New Relic user API key for NerdGraph   |
| `region` | string | 否  | New Relic data center region: us or eu |
| `guid`   | string | 是  | Entity GUID                            |

输出 [#输出-2]

| 参数             | 类型     | 描述                       |
| -------------- | ------ | ------------------------ |
| `entity`       | object | New Relic entity details |
| ↳ `guid`       | string | Entity GUID              |
| ↳ `name`       | string | Entity name              |
| ↳ `entityType` | string | Entity type              |

new_relic_create_deployment_event [#new_relic_create_deployment_event]

Record a deployment change event in New Relic change tracking.

输入 [#输入-3]

| 参数                 | 类型     | 必填 | 描述                                                                                     |
| ------------------ | ------ | -- | -------------------------------------------------------------------------------------- |
| `apiKey`           | string | 是  | New Relic user API key for NerdGraph                                                   |
| `region`           | string | 否  | New Relic data center region: us or eu                                                 |
| `entityGuid`       | string | 是  | GUID of the entity associated with the deployment                                      |
| `version`          | string | 是  | Deployment version, release name, or commit SHA                                        |
| `shortDescription` | string | 否  | Short description of the deployment                                                    |
| `description`      | string | 否  | Longer deployment description                                                          |
| `changelog`        | string | 否  | Deployment changelog text or URL                                                       |
| `commit`           | string | 否  | Commit SHA or identifier associated with the deployment                                |
| `deepLink`         | string | 否  | URL to the deployment, build, or release details                                       |
| `user`             | string | 否  | User or automation that performed the deployment                                       |
| `groupId`          | string | 否  | Optional group ID to correlate related changes                                         |
| `customAttributes` | json   | 否  | Custom change event metadata as key-value pairs with string, number, or boolean values |
| `deploymentType`   | string | 否  | Deployment type: basic, blue green, canary, rolling, or shadow                         |
| `timestamp`        | number | 否  | Event timestamp in milliseconds since Unix epoch                                       |

输出 [#输出-3]

| 参数                   | 类型     | 描述                                                          |
| -------------------- | ------ | ----------------------------------------------------------- |
| `event`              | object | Created New Relic change tracking event                     |
| ↳ `changeTrackingId` | string | New Relic change tracking ID                                |
| ↳ `customAttributes` | json   | Custom attributes on the change tracking event              |
| ↳ `category`         | string | Change category                                             |
| ↳ `categoryAndType`  | string | Combined category and type                                  |
| ↳ `type`             | string | Change type                                                 |
| ↳ `shortDescription` | string | Short change description                                    |
| ↳ `description`      | string | Change description                                          |
| ↳ `timestamp`        | number | Change timestamp in milliseconds                            |
| ↳ `user`             | string | User associated with the change                             |
| ↳ `groupId`          | string | Change group ID                                             |
| ↳ `entity`           | object | Entity associated with the change                           |
| ↳ `guid`             | string | Entity GUID                                                 |
| ↳ `name`             | string | Entity name                                                 |
| `messages`           | array  | Messages returned by New Relic for the created change event |
