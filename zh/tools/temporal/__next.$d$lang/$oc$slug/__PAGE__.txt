使用说明 [#使用说明]

Connect to a Temporal cluster over the server's HTTP API to start workflow executions, send signals, run queries against workflow state, describe and list executions, fetch event histories, and cancel or terminate running workflows. API key only required for servers with authentication enabled.

工具 [#工具]

temporal_start_workflow [#temporal_start_workflow]

Start a new workflow execution on a Temporal cluster.

输入 [#输入]

| 参数                         | 类型     | 必填 | 描述                                                                                                                                                                                                                                                          |
| -------------------------- | ------ | -- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `serverUrl`                | string | 是  | Base URL of the Temporal server's HTTP API (e.g., [http://localhost:7243\\](http://localhost:7243\\))                                                                                                                                                       |
| `namespace`                | string | 是  | Temporal namespace (e.g., default)                                                                                                                                                                                                                          |
| `apiKey`                   | string | 否  | API key sent as a Bearer token (leave blank for servers without auth)                                                                                                                                                                                       |
| `workflowId`               | string | 是  | Unique workflow ID for the new execution (e.g., order-1234)                                                                                                                                                                                                 |
| `workflowType`             | string | 是  | Registered workflow type name to run (e.g., OrderWorkflow)                                                                                                                                                                                                  |
| `taskQueue`                | string | 是  | Task queue the workflow worker polls (e.g., orders)                                                                                                                                                                                                         |
| `input`                    | string | 否  | Workflow input as JSON. A top-level array is passed as the argument list (one argument per element); any other value is passed as a single argument                                                                                                         |
| `workflowIdReusePolicy`    | string | 否  | Policy for reusing a closed workflow ID: WORKFLOW\_ID\_REUSE\_POLICY\_ALLOW\_DUPLICATE, WORKFLOW\_ID\_REUSE\_POLICY\_ALLOW\_DUPLICATE\_FAILED\_ONLY, WORKFLOW\_ID\_REUSE\_POLICY\_REJECT\_DUPLICATE, or WORKFLOW\_ID\_REUSE\_POLICY\_TERMINATE\_IF\_RUNNING |
| `workflowIdConflictPolicy` | string | 否  | Policy when a workflow with the same ID is already running: WORKFLOW\_ID\_CONFLICT\_POLICY\_FAIL, WORKFLOW\_ID\_CONFLICT\_POLICY\_USE\_EXISTING, or WORKFLOW\_ID\_CONFLICT\_POLICY\_TERMINATE\_EXISTING                                                     |
| `cronSchedule`             | string | 否  | Cron schedule for recurring executions (e.g., "0 12 \* \* \*")                                                                                                                                                                                              |
| `executionTimeoutSeconds`  | number | 否  | Total workflow execution timeout in seconds, including retries and continue-as-new                                                                                                                                                                          |
| `runTimeoutSeconds`        | number | 否  | Timeout for a single workflow run in seconds                                                                                                                                                                                                                |
| `memo`                     | string | 否  | JSON object of memo fields to attach to the execution                                                                                                                                                                                                       |
| `searchAttributes`         | string | 否  | JSON object of search attribute values to index the execution with                                                                                                                                                                                          |

输出 [#输出]

| 参数           | 类型      | 描述                                                                                |
| ------------ | ------- | --------------------------------------------------------------------------------- |
| `workflowId` | string  | Workflow ID of the execution                                                      |
| `runId`      | string  | Run ID of the started workflow execution                                          |
| `started`    | boolean | Whether a new execution was started (false when an existing execution was reused) |

temporal_signal_workflow [#temporal_signal_workflow]

Send a signal to a running Temporal workflow execution.

输入 [#输入-1]

| 参数            | 类型     | 必填 | 描述                                                                                                                                                |
| ------------- | ------ | -- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `serverUrl`   | string | 是  | Base URL of the Temporal server's HTTP API (e.g., [http://localhost:7243\\](http://localhost:7243\\))                                             |
| `namespace`   | string | 是  | Temporal namespace (e.g., default)                                                                                                                |
| `apiKey`      | string | 否  | API key sent as a Bearer token (leave blank for servers without auth)                                                                             |
| `workflowId`  | string | 是  | Workflow ID of the execution to signal                                                                                                            |
