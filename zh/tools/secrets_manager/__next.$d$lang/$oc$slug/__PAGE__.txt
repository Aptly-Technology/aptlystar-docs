使用说明 [#使用说明]

Integrate AWS Secrets Manager into the workflow. Can retrieve, create, update, list, and delete secrets.

工具 [#工具]

secrets_manager_get_secret [#secrets_manager_get_secret]

Retrieve a secret value from AWS Secrets Manager

输入 [#输入]

| 参数                | 类型     | 必填 | 描述                                                                           |
| ----------------- | ------ | -- | ---------------------------------------------------------------------------- |
| `region`          | string | 是  | AWS region (e.g., us-east-1)                                                 |
| `accessKeyId`     | string | 是  | AWS access key ID                                                            |
| `secretAccessKey` | string | 是  | AWS secret access key                                                        |
| `secretId`        | string | 是  | The name or ARN of the secret to retrieve                                    |
| `versionId`       | string | 否  | The unique identifier of the version to retrieve                             |
| `versionStage`    | string | 否  | The staging label of the version to retrieve (e.g., AWSCURRENT, AWSPREVIOUS) |

输出 [#输出]

| 参数              | 类型     | 描述                                      |
| --------------- | ------ | --------------------------------------- |
| `name`          | string | Name of the secret                      |
| `secretValue`   | string | The decrypted secret value              |
| `arn`           | string | ARN of the secret                       |
| `versionId`     | string | Version ID of the secret                |
| `versionStages` | array  | Staging labels attached to this version |
| `createdDate`   | string | Date the secret was created             |

secrets_manager_list_secrets [#secrets_manager_list_secrets]

List secrets stored in AWS Secrets Manager

输入 [#输入-1]

| 参数                | 类型     | 必填 | 描述                                                       |
| ----------------- | ------ | -- | -------------------------------------------------------- |
| `region`          | string | 是  | AWS region (e.g., us-east-1)                             |
| `accessKeyId`     | string | 是  | AWS access key ID                                        |
| `secretAccessKey` | string | 是  | AWS secret access key                                    |
| `maxResults`      | number | 否  | Maximum number of secrets to return (1-100, default 100) |
| `nextToken`       | string | 否  | Pagination token from a previous request                 |

输出 [#输出-1]

| 参数          | 类型     | 描述                                                     |
| ----------- | ------ | ------------------------------------------------------ |
| `secrets`   | json   | List of secrets with name, ARN, description, and dates |
| `nextToken` | string | Pagination token for the next page of results          |
| `count`     | number | Number of secrets returned                             |

secrets_manager_create_secret [#secrets_manager_create_secret]

Create a new secret in AWS Secrets Manager

输入 [#输入-2]

| 参数                | 类型     | 必填 | 描述                                           |
| ----------------- | ------ | -- | -------------------------------------------- |
| `region`          | string | 是  | AWS region (e.g., us-east-1)                 |
| `accessKeyId`     | string | 是  | AWS access key ID                            |
| `secretAccessKey` | string | 是  | AWS secret access key                        |
| `name`            | string | 是  | Name of the secret to create                 |
| `secretValue`     | string | 是  | The secret value (plain text or JSON string) |
| `description`     | string | 否  | Description of the secret                    |

输出 [#输出-2]

| 参数          | 类型     | 描述                               |
| ----------- | ------ | -------------------------------- |
| `message`   | string | Operation status message         |
| `name`      | string | Name of the created secret       |
| `arn`       | string | ARN of the created secret        |
| `versionId` | string | Version ID of the created secret |

secrets_manager_update_secret [#secrets_manager_update_secret]

Update the value of an existing secret in AWS Secrets Manager

输入 [#输入-3]

| 参数                | 类型     | 必填 | 描述                                               |
| ----------------- | ------ | -- | ------------------------------------------------ |
| `region`          | string | 是  | AWS region (e.g., us-east-1)                     |
| `accessKeyId`     | string | 是  | AWS access key ID                                |
| `secretAccessKey` | string | 是  | AWS secret access key                            |
| `secretId`        | string | 是  | The name or ARN of the secret to update          |
| `secretValue`     | string | 是  | The new secret value (plain text or JSON string) |
| `description`     | string | 否  | Updated description of the secret                |

输出 [#输出-3]

| 参数          | 类型     | 描述                               |
| ----------- | ------ | -------------------------------- |
| `message`   | string | Operation status message         |
| `name`      | string | Name of the updated secret       |
| `arn`       | string | ARN of the updated secret        |
| `versionId` | string | Version ID of the updated secret |

secrets_manager_delete_secret [#secrets_manager_delete_secret]

Delete a secret from AWS Secrets Manager

输入 [#输入-4]

| 参数                     | 类型      | 必填 | 描述                                                          |
| ---------------------- | ------- | -- | ----------------------------------------------------------- |
| `region`               | string  | 是  | AWS region (e.g., us-east-1)                                |
| `accessKeyId`          | string  | 是  | AWS access key ID                                           |
| `secretAccessKey`      | string  | 是  | AWS secret access key                                       |
| `secretId`             | string  | 是  | The name or ARN of the secret to delete                     |
| `recoveryWindowInDays` | number  | 否  | Number of days before permanent deletion (7-30, default 30) |
| `forceDelete`          | boolean | 否  | If true, immediately delete without recovery window         |

输出 [#输出-4]

| 参数             | 类型     | 描述                         |
| -------------- | ------ | -------------------------- |
| `message`      | string | Operation status message   |
| `name`         | string | Name of the deleted secret |
| `arn`          | string | ARN of the deleted secret  |
| `deletionDate` | string | Scheduled deletion date    |
