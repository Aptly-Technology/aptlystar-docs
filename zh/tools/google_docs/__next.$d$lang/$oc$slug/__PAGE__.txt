[Google Docs](https://docs.google.com) 是一个功能强大的基于云的文档创建和编辑服务，允许用户实时创建、编辑和协作处理文档。作为 Google 办公套件的一部分，Google Docs 提供了一个多功能的平台，用于文本文档的格式化、评论和共享功能。

了解如何在 Aptlystar 中集成 Google Docs 的“读取”工具，轻松从文档中获取数据并将其集成到您的工作流程中。本教程将引导您连接 Google Docs、设置数据读取，并使用这些信息实时自动化流程。非常适合与您的代理同步实时数据。

{/* VIDEO_PLACEHOLDER */}

了解如何在 Aptlystar 中集成 Google Docs 的“更新”工具，通过您的工作流程轻松向文档添加内容。本教程将引导您连接 Google Docs、配置数据写入，并使用这些信息无缝自动更新文档。非常适合以最小的努力维护动态的实时文档。

{/* VIDEO_PLACEHOLDER */}

了解如何在 Aptlystar 中集成 Google Docs 的“创建”工具，通过您的工作流程轻松生成新文档。本教程将引导您连接 Google Docs、设置文档创建，并使用工作流程数据自动填充内容。非常适合简化文档生成并提高生产力。

{/* VIDEO_PLACEHOLDER */}

使用 Google Docs，您可以：

* **创建和编辑文档**：使用全面的格式选项开发文本文档
* **实时协作**：与多位用户同时在同一文档上工作
* **跟踪更改**：查看修订历史并恢复以前的版本
* **评论和建议**：提供反馈并提出编辑建议，而不更改原始内容
* **随时随地访问**：通过设备使用 Google Docs，并自动同步到云端
* **离线工作**：在没有互联网连接的情况下继续工作，重新联网时同步更改
* **与其他服务集成**：连接 Google Drive、Sheets、Slides 和第三方应用程序

在 Aptlystar 中，Google Docs 集成使您的代理可以以编程方式直接与文档内容交互。这支持强大的自动化场景，例如文档创建、内容提取、协作编辑和文档管理。您的代理可以读取现有文档以提取信息，写入文档以更新内容，并从头创建新文档。此集成弥合了您的 AI 工作流与文档管理之间的差距，使您能够无缝地与世界上最广泛使用的文档平台之一进行交互。通过将 Aptlystar 与 Google Docs 连接，您可以自动化文档工作流、生成报告、从文档中提取见解并维护文档——所有这些都通过您的智能代理完成。

将 Google Docs 集成到工作流程中。可以读取、编辑和创建文档。需要 OAuth 授权。

google_docs_read [#google_docs_read]

从 Google Docs 文档中读取内容

输入 [#输入]

| 参数           | 类型     | 必需 | 描述        |
| ------------ | ------ | -- | --------- |
| `documentId` | string | 是  | 要读取的文档 ID |

输出 [#输出]

| 参数         | 类型     | 描述                   |
| ---------- | ------ | -------------------- |
| `content`  | string | 提取的文档文本内容            |
| `metadata` | json   | 包括 ID、标题和 URL 的文档元数据 |

google_docs_write [#google_docs_write]

在 Google Docs 文档中写入或更新内容

输入 [#输入-1]

| `documentId` | string | 是  | 要写入的文档 ID |
| `content`    | string | 是  | 要写入文档的内容  |

输出 [#输出-1]

| 参数               | 类型      | 描述                      |
| ---------------- | ------- | ----------------------- |
| `updatedContent` | boolean | 表示文档内容是否成功更新            |
| `metadata`       | json    | 更新后的文档元数据，包括 ID、标题和 URL |
