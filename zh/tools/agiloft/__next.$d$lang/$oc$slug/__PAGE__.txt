使用说明 [#使用说明]

Integrate with Agiloft contract lifecycle management to create, read, update, delete, and search records. Supports file attachments, SQL-based selection, saved searches, and record locking across any table in your knowledge base.

工具 [#工具]

agiloft_attach_file [#agiloft_attach_file]

Attach a file to a field in an Agiloft record.

输入 [#输入]

| 参数              | 类型     | 必填 | 描述                                                                                              |
| --------------- | ------ | -- | ----------------------------------------------------------------------------------------------- |
| `instanceUrl`   | string | 是  | Agiloft instance URL (e.g., [https://mycompany.agiloft.com\\](https://mycompany.agiloft.com\\)) |
| `knowledgeBase` | string | 是  | Knowledge base name                                                                             |
| `login`         | string | 是  | Agiloft username                                                                                |
| `password`      | string | 是  | Agiloft password                                                                                |
| `table`         | string | 是  | Table name (e.g., "contracts")                                                                  |
| `recordId`      | string | 是  | ID of the record to attach the file to                                                          |
| `fieldName`     | string | 是  | Name of the attachment field                                                                    |
| `file`          | file   | 否  | File to attach                                                                                  |
| `fileName`      | string | 否  | Name to assign to the file (defaults to original file name)                                     |

输出 [#输出]

| 参数                 | 类型     | 描述                                                              |
| ------------------ | ------ | --------------------------------------------------------------- |
| `recordId`         | string | ID of the record the file was attached to                       |
| `fieldName`        | string | Name of the field the file was attached to                      |
| `fileName`         | string | Name of the attached file                                       |
| `totalAttachments` | number | Total number of files attached in the field after the operation |

agiloft_attachment_info [#agiloft_attachment_info]

Get information about file attachments on a record field.

输入 [#输入-1]

| 参数              | 类型     | 必填 | 描述                                                                                              |
| --------------- | ------ | -- | ----------------------------------------------------------------------------------------------- |
| `instanceUrl`   | string | 是  | Agiloft instance URL (e.g., [https://mycompany.agiloft.com\\](https://mycompany.agiloft.com\\)) |
| `knowledgeBase` | string | 是  | Knowledge base name                                                                             |
| `login`         | string | 是  | Agiloft username                                                                                |
| `password`      | string | 是  | Agiloft password                                                                                |
| `table`         | string | 是  | Table name (e.g., "contracts")                                                                  |
| `recordId`      | string | 是  | ID of the record to check attachments on                                                        |
| `fieldName`     | string | 是  | Name of the attachment field to inspect                                                         |

输出 [#输出-1]

| 参数            | 类型     | 描述                                                |
| ------------- | ------ | ------------------------------------------------- |
| `attachments` | array  | List of attachments with position, name, and size |
| ↳ `position`  | number | Position index of the attachment in the field     |
| ↳ `name`      | string | File name of the attachment                       |
| ↳ `size`      | number | File size in bytes                                |
| `totalCount`  | number | Total number of attachments in the field          |
