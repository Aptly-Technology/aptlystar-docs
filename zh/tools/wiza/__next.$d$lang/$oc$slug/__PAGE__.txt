使用说明 [#使用说明]

Integrates Wiza into the workflow. Search prospects, enrich companies, reveal verified emails and phone numbers for individuals, and check your account credit balance.

工具 [#工具]

wiza_prospect_search [#wiza_prospect_search]

Search Wiza

输入 [#输入]

| 参数                 | 类型     | 必填 | 描述                                                                                 |
| ------------------ | ------ | -- | ---------------------------------------------------------------------------------- |
| `apiKey`           | string | 是  | Wiza API key                                                                       |
| `size`             | number | 否  | Number of sample profiles to return (0-30, default 0)                              |
| `filters`          | object | 否  | Full filters object (overrides individual filter params if provided)               |
| `first_name`       | array  | 否  | Exact first names to match (e.g., \["John", "Jane"])                               |
| `last_name`        | array  | 否  | Exact last names to match                                                          |
| `job_title`        | array  | 否  | Job titles to include/exclude (e.g., \[\{"v":"CEO","s":"i"},\{"v":"CTO","s":"e"}]) |
| `job_title_level`  | array  | 否  | Seniority levels (e.g., \["cxo", "director", "manager"])                           |
| `job_role`         | array  | 否  | Job role categories (e.g., \["sales", "engineering", "marketing"])                 |
| `job_sub_role`     | array  | 否  | Detailed role categories (e.g., \["software", "product"])                          |
| `location`         | array  | 否  | Person's location filters (city/state/country with include/exclude)                |
| `skill`            | array  | 否  | Professional skills (e.g., \["python", "marketing"])                               |
| `school`           | array  | 否  | Educational institutions                                                           |
| `major`            | array  | 否  | Field of study                                                                     |
| `linkedin_slug`    | array  | 否  | LinkedIn profile slugs                                                             |
| `job_company`      | array  | 否  | Current company filters (include/exclude)                                          |
| `past_company`     | array  | 否  | Past company filters                                                               |
| `company_location` | array  | 否  | Company HQ location filters                                                        |
| `company_industry` | array  | 否  | Company industry filters (include/exclude)                                         |
| `company_size`     | array  | 否  | Company headcount brackets (e.g., \["1-10", "11-50", "51-200"])                    |
| `company_type`     | array  | 否  | Company type (e.g., \["private", "public", "educational"])                         |

输出 [#输出]

| 参数         | 类型     | 描述                                           |
| ---------- | ------ | -------------------------------------------- |
| `total`    | number | Total number of matching prospects           |
| `profiles` | array  | Sample profiles matching the filter criteria |

| `domain`           | string  | 否  | Company domain (used with full\_name)                                                               |
| `email`            | string  | 否  | Email address (use alone or with other identifiers)                                                 |
