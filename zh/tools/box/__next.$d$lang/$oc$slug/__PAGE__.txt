使用说明 [#使用说明]

Integrate Box into your workflow to manage files, folders, and e-signatures. Upload and download files, search content, create folders, send documents for e-signature, track signing status, and more.

工具 [#工具]

box_upload_file [#box_upload_file]

Upload a file to a Box folder

输入 [#输入]

| 参数               | 类型     | 必填 | 描述                                                            |
| ---------------- | ------ | -- | ------------------------------------------------------------- |
| `parentFolderId` | string | 是  | The ID of the folder to upload the file to (use "0" for root) |
| `file`           | file   | 否  | The file to upload (UserFile object)                          |
| `fileContent`    | string | 否  | Legacy: base64 encoded file content                           |
| `fileName`       | string | 否  | Optional filename override                                    |

输出 [#输出]

| 参数           | 类型     | 描述                        |
| ------------ | ------ | ------------------------- |
| `id`         | string | File ID                   |
| `name`       | string | File name                 |
| `size`       | number | File size in bytes        |
| `sha1`       | string | SHA1 hash of file content |
| `createdAt`  | string | Creation timestamp        |
| `modifiedAt` | string | Last modified timestamp   |
| `parentId`   | string | Parent folder ID          |
| `parentName` | string | Parent folder name        |

Download a file from Box

输入 [#输入-1]

| 参数       | 类型     | 必填 | 描述                             |
| -------- | ------ | -- | ------------------------------ |
| `fileId` | string | 是  | The ID of the file to download |

输出 [#输出-1]

| 参数        | 类型     | 描述                                        |
| --------- | ------ | ----------------------------------------- |
| `file`    | file   | Downloaded file stored in execution files |
