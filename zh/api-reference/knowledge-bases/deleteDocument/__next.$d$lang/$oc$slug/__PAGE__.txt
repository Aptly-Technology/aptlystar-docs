`DELETE /api/v1/knowledge/{id}/documents/{documentId}`

## Description
Soft-delete a document from a knowledge base. For connector-sourced documents, this also prevents re-import on future syncs.

## Parameters

- **id** (path) (required) — `string`: Knowledge base ID.

- **documentId** (path) (required) — `string`: Document ID.

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.
