`GET /api/v1/knowledge/{id}/documents`

## Description
List documents in a knowledge base with pagination, filtering, and sorting.

## Parameters

- **id** (path) (required) — `string`: Knowledge base ID.

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.

- **limit** (query) — `integer`: Maximum number of documents to return (1-100, default 50).

- **offset** (query) — `integer`: Number of documents to skip (default 0).

- **search** (query) — `string`: Search documents by filename.

- **enabledFilter** (query) — `string`: Filter by enabled status.

- **sortBy** (query) — `string`: Field to sort by.

- **sortOrder** (query) — `string`: Sort direction.
