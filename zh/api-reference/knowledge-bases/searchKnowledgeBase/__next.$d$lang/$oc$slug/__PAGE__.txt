`POST /api/v1/knowledge/search`

## Description
Perform vector similarity search across one or more knowledge bases. Supports semantic search via query text, tag-based filtering, or a combination of both.

## Request Body

{
  "type": "object",

    "knowledgeBaseIds"

    "knowledgeBaseIds": {
