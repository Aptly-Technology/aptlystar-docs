`GET /api/v1/tables/{tableId}/rows`

## Description
Query rows from a table with optional filtering, sorting, and pagination. Filters and sorts are passed as JSON-encoded query parameters.

## Parameters

- **tableId** (path) (required) — `string`: The unique identifier of the table.

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.

- **filter** (query) — `string`: JSON-encoded filter object. Example: {"status": "active"} or {"age": {"$gt": 18}}.

- **sort** (query) — `string`: JSON-encoded sort object. Example: {"created_at": "desc"}.

- **limit** (query) — `integer`: Maximum rows to return (1-1000, default 100).

- **offset** (query) — `integer`: Number of rows to skip for pagination (default 0).
