`GET /api/v1/logs`

## Description
List workflow execution logs with advanced filtering and cursor-based pagination. Supports filtering by workflow, trigger type, date range, duration, cost, and more.

## Parameters

- **workspaceId** (query) (required) — `string`: The unique identifier of the workspace.

- **workflowIds** (query) — `string`: Comma-separated list of workflow IDs to filter by. Only logs from these workflows will be returned.

- **folderIds** (query) — `string`: Comma-separated list of folder IDs. Returns logs for all workflows within these folders.

- **triggers** (query) — `string`: Comma-separated trigger types to filter by: api, webhook, schedule, manual, chat.

- **level** (query) — `string`: Filter logs by severity level. info for successful executions, error for failed ones.

- **startDate** (query) — `string`: Only return logs after this ISO 8601 timestamp (inclusive).

- **endDate** (query) — `string`: Only return logs before this ISO 8601 timestamp (inclusive).

- **executionId** (query) — `string`: Filter by an exact execution ID. Useful for looking up a specific run.

- **minDurationMs** (query) — `integer`: Only return logs where execution took at least this many milliseconds.

- **maxDurationMs** (query) — `integer`: Only return logs where execution took at most this many milliseconds.

- **minCost** (query) — `number`: Only return logs where execution cost at least this amount in USD.

- **maxCost** (query) — `number`: Only return logs where execution cost at most this amount in USD.

- **model** (query) — `string`: Filter by the AI model used during execution (e.g., gpt-4o, claude-opus-4-6).

- **details** (query) — `string`: Response detail level. basic returns summary fields only. full includes execution data, trace spans, and outputs.

- **includeTraceSpans** (query) — `boolean`: When true, includes block-level execution trace spans with timing and input/output data.

- **includeFinalOutput** (query) — `boolean`: When true, includes the workflow's final output in each log entry.

- **limit** (query) — `integer`: Maximum number of log entries to return per page.

- **cursor** (query) — `string`: Pagination cursor returned from a previous request's nextCursor field.

- **order** (query) — `string`: Sort order by execution start time. desc returns newest first.
